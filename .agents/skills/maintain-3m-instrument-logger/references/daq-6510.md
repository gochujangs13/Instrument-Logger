# DAQ-6510

- Module: `instruments/daq_6510.js`
- View: custom
- Serial fallback: 9600, 8-N-1
- Supports front-terminal direct measurement and rear-slot scanning.

Read the DAQ section of `docs/INSTRUMENT_COMMUNICATION_PROTOCOLS.md` and the current module before changing routing.

## Invariants

- Keep FRONT and REAR workflows separate.
- Wait for reset completion using the module's startup state handling.
- Preserve slot detection and channel identity.
- In FRES mode, respect four-wire channel pairing and reject conflicting pair selections.
- Use only routing commands verified for DAQ-6510; do not copy legacy Keithley 2700 scan commands.
- Keep scan polling/chaining single-flight so responses match pending state.
- Stop scans, cycles, callbacks, relays, and graph timers on disconnect.
