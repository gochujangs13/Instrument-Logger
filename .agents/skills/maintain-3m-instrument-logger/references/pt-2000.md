# PT-2000 Probe Tack

- Module: `instruments/pt2000_probe_tack.js`
- View: custom
- Transport: WebHID, self-managed
- Module flag: `noAutoConnect`

Do not route PT-2000 through `SerialController`. Preserve HID report parsing, pending-response timeout behavior, watchdog/poll cleanup, test sequence, result grouping, outlier handling, and Excel export.

On disconnect or navigation, close/forget the active HID state as implemented and clear watchdog, polling, pending response, and proceed timers. Require a compatible browser and physical-device test for HID changes.
