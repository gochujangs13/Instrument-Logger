# 해상도가 바뀌어도 비율이 유지되는 레이아웃 가이드

> 3M Instrument Logger에서 실제로 사용 중인 방식을 다른 프로그램에도 적용할 수 있도록 정리한
> 전달용 문서입니다. 웹 기반 UI(브라우저, Electron, pywebview 등)라면 그대로 쓸 수 있습니다.

## 핵심 개념 한 줄 요약

**요소 크기를 픽셀로 고정하지 말고, "화면을 나눠 갖는 규칙"으로 정의한다.**

창 크기가 바뀌면 각 영역이 규칙에 따라 공간을 다시 나눠 가지므로,
어떤 해상도에서도 전체 구도(비율)가 똑같이 유지된다.

---

## 원칙 1. 페이지 전체가 항상 창 크기 100%를 채우게

```css
html, body { height: 100%; overflow: hidden; }  /* 페이지 자체는 절대 스크롤되지 않음 */
body {
  margin: 0;
  display: flex;
  flex-direction: column;   /* 상단바 → 본문 순서로 세로로 쌓음 */
}
#topbar { flex-shrink: 0; height: 54px; }  /* 상단바처럼 고정 높이가 필요한 것만 고정 */
#main   { flex: 1; min-height: 0; }        /* 본문이 남는 세로 공간을 전부 차지 */
```

- `height: 100%` + `overflow: hidden`으로 "페이지 = 창"이 됩니다.
- 본문에 `flex: 1`을 주면 창 높이가 얼마든 남는 공간을 전부 채웁니다.

HTML `<head>`에는 뷰포트 메타 태그 필수:

```html
<meta name="viewport" content="width=device-width, initial-scale=1.0">
```

그리고 모든 요소에 border-box 적용 (패딩/테두리로 인한 크기 계산 오차 방지):

```css
*, *::before, *::after { box-sizing: border-box; }
```

## 원칙 2. 다단 레이아웃은 "고정 | 1fr | 고정" 그리드로

```css
:root {
  --sidebar-w: 290px;   /* 좌측 사이드바 폭 */
  --right-w:   360px;   /* 우측 패널 폭 */
}
#layout {
  flex: 1;
  display: grid;
  grid-template-columns: var(--sidebar-w) minmax(0, 1fr) var(--right-w);
  gap: 12px;
  padding: 12px;
  min-height: 0;
  overflow: hidden;
}
```

- 좌우 패널은 고정 폭, **가운데(`1fr`)가 창 크기 변화량을 전부 흡수**합니다.
- ⚠️ **`minmax(0, 1fr)`의 `0`이 매우 중요** — 그냥 `1fr`만 쓰면 가운데에 긴 표나 넓은
  내용이 들어갔을 때 그리드가 밀려나 우측 패널이 화면 밖으로 잘립니다.
  (실제로 이 문제를 겪고 `minmax(0, 1fr)`로 고쳤음.)

## 원칙 3. 모든 flex/grid 자식에 `min-height: 0` / `min-width: 0`

```css
aside, #center {
  display: flex; flex-direction: column;
  gap: 10px;
  min-height: 0;   /* ← 이 두 줄이 없으면 */
  min-width: 0;    /* ← 창을 줄일 때 레이아웃이 깨짐 */
}
.panel.grow { flex: 1; min-height: 0; }
```

- **가장 많이 걸리는 함정**: flex/grid 자식은 기본값이 `min-size: auto`라서
  내용물보다 작아지길 거부합니다. 창을 줄이면 자식이 안 줄어들고 밖으로 삐져나옵니다.
- `min-height: 0` / `min-width: 0`을 명시하면 규칙대로 줄어듭니다.

---

## 원칙 4. 스크롤은 페이지가 아니라 각 영역 내부에서

```css
.sidebar-scroll { flex: 1; min-height: 0; overflow-y: auto; }
.table-scroll   { max-height: 360px; overflow-y: auto; overflow-x: auto; }
```

- 내용이 넘치면 **그 영역 안에서만** 스크롤바가 생깁니다.
- 바깥 프레임(전체 구도)은 절대 변하지 않으므로 비율이 유지됩니다.
- 참고: 영역 내부 스크롤을 쓸 때, 그 안에 띄우는 드롭다운/팝오버는 `position: absolute`
  대신 `position: fixed` + `getBoundingClientRect()` 좌표 계산을 쓰는 게 안전합니다
  (스크롤 영역·sticky 헤더에 잘리거나 어긋나는 문제 방지 — 실제로 겪은 버그).

## 원칙 5. 그래프(canvas)는 그릴 때마다 컨테이너 실측 크기로

canvas는 HTML 속성으로 크기를 고정하면 해상도가 바뀔 때 찌그러집니다.
**그리기 직전에 부모 컨테이너의 실제 크기를 읽어서** 캔버스 해상도를 맞추세요.

```css
.graph-wrap { position: relative; height: 180px; }   /* 높이는 컨테이너가 결정 */
canvas#chart { width: 100%; height: 100%; display: block; }
```

```js
function drawGraph() {
  const canvas = document.getElementById('chart');
  const wrap = canvas.parentElement;
  const W = wrap.clientWidth, H = wrap.clientHeight;   // 지금 실제 크기를 실측
  if (!W || !H) return;
  if (canvas.width !== W)  canvas.width  = W;          // 캔버스 픽셀 해상도를 맞춤
  if (canvas.height !== H) canvas.height = H;
  const ctx = canvas.getContext('2d');

  // 이후 모든 좌표는 W/H에 대한 비율로 계산 — 고정 픽셀 좌표를 쓰지 않음
  const P = { t: 10, r: 48, b: 28, l: 52 };            // 여백만 고정
  const cw = W - P.l - P.r, ch = H - P.t - P.b;        // 그리기 영역은 실측 기반
  // 예: x = P.l + cw * (t - tMin) / (tMax - tMin);
  //     y = P.t + ch * (1 - value / yMax);
}
```

## 보너스: 작은 화면 대응 (단계적 축소)

창이 일정 폭보다 좁아지면 덜 중요한 패널부터 숨겨서 핵심 영역을 지킵니다.

```css
@media (max-width: 1100px) {
  #layout { grid-template-columns: 260px 1fr; }
  #rightpanel { display: none; }        /* 좁으면 우측 패널 숨김 */
}
@media (max-width: 780px) {
  #layout { grid-template-columns: 1fr; }
  #sidebar { display: none; }           /* 더 좁으면 사이드바도 숨김 */
}
```

## 하지 말아야 할 것 (안티패턴)

| 안티패턴 | 왜 문제인가 | 대신 이렇게 |
|---|---|---|
| `width: 1200px` 같은 전체 고정 폭 | 다른 해상도에서 잘리거나 빈 공간 발생 | `1fr` / `flex: 1`로 나눠 갖기 |
| `position: absolute; top: 500px` 절대 좌표 배치 | 해상도 바뀌면 위치가 어긋남 | flex/grid 흐름 배치 |
| canvas에 `width="800" height="400"` 고정 | 리사이즈 시 찌그러지거나 흐려짐 | 그릴 때 `clientWidth/Height` 실측 |
| 페이지 전체 스크롤(`body` 스크롤)에 의존 | 창 크기마다 보이는 구도가 달라짐 | 영역별 내부 스크롤 |
| flex 자식에 `min-height` 미지정 | 창 축소 시 내용물이 삐져나옴 | `min-height: 0` 명시 |

## 체크리스트 (새 프로그램에 적용할 때)

- [ ] `<meta name="viewport" ...>` 추가했는가
- [ ] `html, body { height: 100%; overflow: hidden }` 인가
- [ ] `box-sizing: border-box` 전역 적용했는가
- [ ] 본문 레이아웃이 `고정 | minmax(0, 1fr) | 고정` 패턴인가
- [ ] 모든 flex/grid 자식에 `min-height: 0` / `min-width: 0` 넣었는가
- [ ] 스크롤이 페이지가 아니라 영역 내부에 있는가
- [ ] canvas를 그릴 때마다 컨테이너 크기를 실측하는가
- [ ] 좁은 화면용 `@media` 단계적 축소가 있는가
