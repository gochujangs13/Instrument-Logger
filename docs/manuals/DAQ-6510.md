# Keithley DAQ-6510 (다채널 저항 로거) — 사용 매뉴얼

스캐너 카드를 통해 최대 10채널의 저항을 순차 측정·장시간 기록하는 데이터 로거입니다. ✅ 실기 테스트 완료.

## 1. 통신 사양

| 항목 | 값 |
|---|---|
| Baud Rate | 9600 |
| Data / Parity / Stop | 8 / None / 1 |
| 종단문자 | CRLF (`\r\n`) |

## 2. Front / Rear 단자 선택

사이드바 상단의 **Front / Rear** 토글로 측정 단자를 선택합니다.

| 모드 | 용도 |
|---|---|
| Front | 전면 4-Wire 단자 **단일 측정점** (스캔 비활성) |
| Rear | 후면 스캐너 카드(슬롯 1/2) — **최대 10채널 순차 측정** |

- Rear 선택 시 장착된 슬롯이 자동 감지됩니다 (`ROUT:SCAN:CAT?`).

## 3. Rear 스캔 동작 원리 (채널별 수동 릴레이 제어)

```
채널마다 반복:
  ROUT:OPEN:ALL           (50ms 대기)
  ROUT:CLOS (@ch, ch+10)  ← 4-wire: 소스+센스 릴레이 동시 (300ms 안정화)
  READ?                   ← 값 수신
  ROUT:OPEN:ALL           ← 릴레이 즉시 해제
  남은 딜레이 대기 → 다음 채널
```

- 4-wire 채널 쌍: 소스 채널 + 10 = 센스 채널 (예: CH101 + CH111)
- 10채널 1사이클 소요 시간 ≈ 채널 수 × (딜레이 + 측정 시간). 딜레이 2초 설정 시 약 22초/사이클

## 4. 앱 사용 절차

1. 런처에서 **DAQ-6510** 카드 클릭
2. Front/Rear 선택 (Rear면 슬롯 자동 감지)
3. **채널 딜레이(초)**, **총 측정 시간**, **기록 간격** 설정
4. 채널별 샘플 이름 설정 (선택): **채널 이름 설정...** 버튼
5. **측정 시작** → 채널별 순차 측정 진행, 값이 즉시 디스플레이에 표시
6. 우측 그래프에 채널별 시계열 실시간 표시
7. 설정한 측정 시간 도달 시 **자동 종료** (종료 예정 시각이 상단에 표시됨)

## 5. 사이드바 설정

| 항목 | 설명 |
|---|---|
| 채널 딜레이 | 채널 간 전환 대기(초) — 릴레이 안정화 시간 |
| 측정 시간 | 총 지속 시간 — 도달 시 자동 정지 |
| 스캔 모드 | 실시간(매 사이클 기록) / 전체 스캔(3분마다 1행 기록 — 장시간용) |
| 측정 방식 | 4-Wire / 2-Wire |

## 6. 그래프 X축

- 데이터 1000행 미만: 실제 경과 시간에 자동 맞춤
- 1000행 이상: 1시간 단위로 스케일 성장 (0→1h→2h…)
- 1시간 미만 구간은 분(m) 단위 라벨

## 7. 문제 해결

| 증상 | 해결 |
|---|---|
| 채널 1개만 측정됨 | Front 모드 상태 — 사이드바에서 **Rear** 선택 |
| 사이클 정지 버튼 눌러도 즉시 안 멈춤 | "사이클 완료 후 정지" — 진행 중 사이클을 마친 후 정지 (정상) |
| -113 에러 | 구버전 문제 — 현재 시퀀스에서 발생하지 않음 |
