# Etching Design — 에칭 패턴 설계·배치 도구

Etching Design은 금속 원판 위 시편 배열을 설계하고, 면적·생산 수량을 계산한 뒤 1:1 CAD/벡터 파일로 내보내는 도구입니다. 장비 통신이나 계측기 연결은 사용하지 않습니다.

## 시작

런처에서 **Etching Design** 카드를 엽니다. 좌측 설정 패널, 중앙 도면 미리보기, 우측 계산·결과 패널의 세 영역으로 구성됩니다.

## 설계 순서

1. **단일 디자인** 또는 **혼합 배치**를 선택합니다.
2. 원판 크기와 여백을 입력합니다. 자동 중앙 정렬 또는 수동 여백을 사용할 수 있습니다.
3. 프리셋(TYPE 1/2/3) 또는 사용자 정의 시편 치수를 선택합니다.
4. 배열 방식을 선택합니다. **열·행 직접 입력**은 사용자가 두 수량을 지정하고, **원판 맞춤 자동 배치**는 원판 크기·시편 크기·여백·가로 지지대 간격·브릿지 위아래 에칭 거리로 들어갈 수 있는 열과 행을 자동 계산합니다. 브릿지 위아래 에칭 거리의 기본값은 모든 타입에서 1mm이며 사용자가 수정할 수 있습니다. 자동 모드의 열·행 칸은 계산 결과를 보여주는 읽기 전용 값입니다.
5. 필요하면 시편 방향, 중앙 시편 방향 예외, 모서리(직각/라운드/모따기), 고정 탭을 설정합니다.
6. 이 프로그램에서 **브릿지**는 15×6mm와 같은 시편 본체를 뜻하고, 원판과 브릿지를 좌우에서 연결하는 좁은 금속부는 **지지대**라고 부릅니다. 위치는 `브릿지 정중앙`, `브릿지 2포인트(좌·우 대칭)`, `브릿지 4포인트(네 모서리)`, `직접 입력` 중 선택합니다. 2포인트는 세로 중앙선에 좌우 대칭으로 배치하고 `좌 홀 ↔ 우 홀 중심 거리`를 입력합니다. 4포인트는 `좌 홀 ↔ 우 홀 중심 거리`와 `상 홀 ↔ 하 홀 중심 거리`를 각각 입력합니다. 사각형 선택 시에도 같은 방식으로 사각형 중심 간 거리를 입력합니다. 전체 배치는 브릿지 중심을 기준으로 대칭이며, 홀/사각형 크기 때문에 외곽선을 침범하는 값은 자동으로 안전 보정합니다. 가공값을 설정하고 중앙 미리보기에서 해당 타입의 브릿지 하나를 클릭한 뒤 위치를 확인하고 **해당 타입 전체 적용**을 누릅니다. 적용 전 설정은 선택 브릿지 미리보기에만 표시되고 제조용 CAD에는 들어가지 않습니다.
7. 중앙 미리보기에서 마우스 휠로 확대·축소하고 드래그로 이동합니다. 전체 도면은 **맞춤**으로 다시 화면에 맞춥니다.
8. 우측에서 총 생산 수량, 점유 면적, 수율, 스크랩, 타입별 배열과 원판 적합 여부를 확인합니다.

설정 변경은 실행 취소/다시 실행 이력에 포함되며 `Ctrl+Z` / `Ctrl+Y`로 되돌릴 수 있습니다. 프로젝트는 `.etching` 파일로 저장·불러오기할 수 있습니다.

원판 가로·세로 치수는 단일 디자인과 혼합 배치가 항상 같은 값을 공유합니다. 입력한 치수는 브라우저 로컬 저장소에 저장되므로 모드 전환, 프리셋 변경, 페이지 재실행 후에도 유지됩니다. `.etching` 프로젝트를 불러오면 불러온 원판 치수가 새로운 공통 저장값이 됩니다.

## 미리보기 토글

캔버스 하단 토글로 치수선, 방향 표시, 그리드, 구획 경계, 지지대, 에칭 제거 영역을 각각 표시하거나 숨길 수 있습니다. 이 토글은 화면 미리보기용입니다. 실제 CAD 제조 출력에 들어가는 형상은 내보내기 모드에서 정합니다.

## CAD 및 이미지 내보내기

- **제조용(Manufacturing)**은 절단선·프레임·러너·탭/브릿지·구획 경계·원판 외곽 등 제조 지오메트리를 내보냅니다. 검토용 치수·텍스트·방향 가이드는 제외됩니다.
- **검토용(Review Drawing)**은 검토에 필요한 치수·텍스트·방향 가이드를 별도 GUIDE 레이어로 포함할 수 있습니다.
- 현재 Etching 화면은 제조 형상을 먼저 DXF로 생성합니다. DXF는 AutoCAD 1:1, 밀리미터 단위입니다. DWG 버튼은 이 DXF를 설치된 ODA File Converter에 전달하고 Audit/Repair를 적용해 AutoCAD 2007 `AC1021` DWG로 변환합니다. ODA File Converter가 설치되지 않았으면 DWG 저장을 중단하고 DXF 사용 또는 변환기 설치를 안내합니다.
- 제조 검증은 원판 초과, 중복/0길이 선, 제조 모드의 가이드 엔티티, 닫히지 않은 에칭 제거 폴리라인 등을 확인합니다. 필수 형상 검증 실패 시 CAD 저장을 차단합니다.

실제 에칭/레이저 공정에 보내기 전에는 제조 담당자가 CAD에서 단위(mm), 레이어, 절단/에칭 제거 방향, 원판 크기와 탭 형상을 다시 확인해야 합니다. 화면 미리보기와 파일 생성만으로 장비별 CAM 공정 검증이 완료되는 것은 아닙니다.
