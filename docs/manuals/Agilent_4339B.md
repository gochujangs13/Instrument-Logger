# Agilent 4339B (고저항 측정기) — 사용 매뉴얼

절연 저항 등 고저항(최대 10^16 Ω)을 측정하는 장비입니다. ✅ 측정 시퀀스 실기 검증 완료.

## 1. 연결 방식 — GPIB

| 항목 | 값 |
|---|---|
| 인터페이스 | **NI GPIB-USB-HS** 어댑터 (VISA형) |
| 필수 드라이버 | NI-488.2 (NI-VISA 포함 패키지) |
| GPIB 주소 | 기본 17번 |

> ⚠ 이 장비는 시리얼(COM 포트)이 아니라 **GPIB-USB** 어댑터로 연결합니다.
> NI-488.2 드라이버가 설치되어 있지 않으면 장치관리자에 ⚠ 경고 아이콘으로 표시되고
> 연결이 불가능합니다. 드라이버 설치 후 PyVISA IPC 브리지를 통해 연결됩니다.

## 2. 측정 시퀀스 (앱이 자동 실행)

```
[초기화] *RST → 2.2s 대기 → *CLS → FUNC 'RES' → SOUR:VOLT → TRIG:SOUR BUS → OUTP ON
[측정]   충전 대기 → ABOR → *CLS → INIT → 0.5s → *TRG → 0.5s → FETC?
[종료]   OUTP OFF → 0.5s → *CLS
```

## 3. 앱 사용 절차

1. 런처에서 **Agilent 4339B** 카드 클릭
2. 사이드바에서 **인가 전압(V)**, **충전 시간(s)**, **두께(mm)** 설정
3. 연결 후 **측정 시작** 클릭
4. 상단 디스플레이에 **충전 카운트다운**(남은 초)이 표시됨
5. 측정 완료 → 값이 테이블에 기록됨 (5 유효숫자, 예: `1.9864E+14 Ω`)
6. 샘플명은 테이블에서 직접 클릭해 편집 가능

## 4. 사이드바 설정

| 항목 | 설명 |
|---|---|
| 인가 전압 (V) | 측정 인가 전압 |
| 충전 시간 (s) | 충전 대기 — 두꺼운 시료일수록 길게 |
| 두께 (mm) | 표면/체적 저항율 계산용 |
| 반복 횟수 | 그룹당 측정 횟수 — 2 이상이면 우측에 수염차트 표시 |

## 5. 표시값 해석

- `FETC?` 응답은 `status,value` 형식 — status가 0이 아니면 **I-Limit**(전류 한계 도달)으로 표시됩니다.
- OL(9.9E+37)은 측정 범위 초과입니다.

## 6. 문제 해결

- **연결 자체가 안 됨**: NI-488.2 드라이버 설치 여부 확인 (장치관리자에서 GPIB-USB-HS가 정상 인식되어야 함)
- **-213 에러**: 구버전 앱에서 발생하던 문제 — 현재 시퀀스에서는 발생하지 않음. 발생 시 장비 전원 재시작 후 재연결
