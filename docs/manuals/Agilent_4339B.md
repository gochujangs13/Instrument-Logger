# Agilent 4339B (고저항 측정기) — 사용 매뉴얼

절연 저항 등 고저항(최대 10^16 Ω)을 측정하는 장비입니다. 2026-08-04 실장비 검증으로
GPIB 측정값 직접 읽기와 `-410` 방지 시퀀스를 확인했습니다.

## 1. 연결 방식 — GPIB

| 항목 | 값 |
|---|---|
| 인터페이스 | **NI GPIB-USB-HS** 어댑터 (VISA형) |
| 필수 드라이버 | NI-488.2 (NI-VISA 포함 패키지) |
| GPIB 주소 | 기본 17번 |

> ⚠ 이 장비는 시리얼(COM 포트)이 아니라 **GPIB-USB** 어댑터로 연결합니다.
> NI-488.2 드라이버가 설치되어 있지 않으면 장치관리자에 ⚠ 경고 아이콘으로 표시되고
> 연결이 불가능합니다. 드라이버 설치 후 PyVISA IPC 브리지를 통해 연결됩니다.

## 2. 측정 시퀀스 (앱이 자동 실행)

```
[초기화] *RST → 2.2s 대기 → *CLS → FUNC 'RES' → SOUR:VOLT → SOUR:CURR:LIM → TRIG:SOUR BUS → OUTP ON
[측정]   충전 대기 → ABOR → *CLS → INIT → 0.5s → *TRG → 0.5s → 측정 응답 직접 읽기
[종료]   OUTP OFF → 0.5s → *CLS
```

4339B는 `*TRG` 후 측정값을 GPIB 출력 큐에 자동으로 준비합니다. 프로그램은 새 쿼리를 보내지 않고
그 값을 직접 읽습니다. 읽기 전에 `FETC?`나 다른 쿼리를 보내면 `-410,"Query INTERRUPTED"`가 발생합니다.

## 3. 앱 사용 절차

1. 런처에서 **Agilent 4339B** 카드 클릭
2. 사이드바에서 **인가 전압(V)**, **전류 상한(I-Lim)**, **충전 시간(s)**, **두께(mm)** 설정
3. 연결 후 **측정 시작** 클릭
4. 상단 디스플레이에 **충전 카운트다운**(남은 초)이 표시됨
5. 측정 완료 → 값이 테이블에 기록됨 (5 유효숫자, 예: `1.9864E+14 Ω`)
6. 샘플명은 테이블에서 직접 클릭해 편집 가능

## 4. 사이드바 설정

| 항목 | 설명 |
|---|---|
| 인가 전압 (V) | 측정 인가 전압 |
| 전류 상한 (I-Lim) | DUT 보호용 전류 제한 — 전압별 허용 범위 안에서 장비에 실제 적용 |
| 충전 시간 (s) | 충전 대기 — 두꺼운 시료일수록 길게 |
| 두께 (mm) | 표면/체적 저항율 계산용 |
| 반복 횟수 | 그룹당 측정 횟수 — 2 이상이면 우측에 수염차트 표시 |

### 전압별 최대 I-Limit

| 시험 전압 | 선택 가능한 최대 I-Limit |
|---:|---:|
| 0~100 V | 10 mA |
| 100 V 초과~250 V | 5 mA |
| 250 V 초과~500 V | 2 mA |
| 500 V 초과~1000 V | 1 mA |

전압을 변경하면 허용되지 않는 I-Limit은 선택할 수 없으며, 기존 선택값이 범위를 벗어나면
프로그램이 해당 전압의 최대 허용값으로 자동 조정합니다. 예를 들어 **500 V에서는 최대 2 mA**입니다.

> ⚠ 16117B Low Noise Test Leads를 사용할 때는 전압과 관계없이 0.5 mA만 사용해야 합니다.
> 현재 앱의 50 mm 전극 구성은 16008B Resistivity Cell 기준입니다.

## 5. 표시값 해석

- 측정 응답은 `status,value` 형식입니다: `0=정상`, `1=Overload`, `2=No-Contact`, `4=Over-Current(I-Limit)`.
- OL(9.9E+37)은 측정 범위 초과입니다.

## 6. 문제 해결

- **연결 자체가 안 됨**: NI-488.2 드라이버 설치 여부 확인 (장치관리자에서 GPIB-USB-HS가 정상 인식되어야 함)
- **-213 에러**: 구버전 앱에서 발생하던 문제 — 현재 시퀀스에서는 발생하지 않음. 발생 시 장비 전원 재시작 후 재연결
- **-410 에러 또는 장비에는 값이 표시되지만 프로그램에는 값이 없음**: 구버전 프로그램이 `*TRG`로 이미 준비된
  측정 응답을 읽기 전에 `FETC?`를 다시 보내 발생할 수 있습니다. 최신 소스는 새 쿼리 없이 VISA `read()`로 직접 읽고,
  응답 읽기가 끝난 후에만 `OUTP OFF`/`*CLS`를 실행합니다.
- **-420 에러**: 응답 대기 중 다음 명령이 전송되었거나 통신이 중단된 경우입니다. 최신 소스로 서버를 다시 시작한 뒤
  재측정하고, 계속 발생하면 시스템 로그의 `[4339B RX]`와 `VISA Read` 오류를 확인합니다.
- 통신 실패는 OL 데이터로 저장하지 않고 `GPIB ERR`로 표시합니다.
