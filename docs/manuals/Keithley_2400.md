# Keithley SourceMeter 2400 사용 매뉴얼

## 1. 장비 용도

Keithley 2400은 DUT에 정밀 전압 또는 전류를 인가하면서 전압, 전류, 저항, 전력을 측정하는 단일 채널 SourceMeter입니다. 이 프로그램은 다음 평가를 지원합니다.

- 단일 포인트: 지정 조건에서 V/I/R/P 반복 기록
- 시간 평가: 고정 전압 또는 전류에서 시간에 따른 값 기록
- I-V Sweep: 시작값과 종료값 사이를 여러 점으로 나누어 순차 측정
- 사이클 평가: 단계마다 인가값, Compliance, 유지시간을 정하고 지정 횟수만큼 반복

배터리 충방전, 외부 전원이 연결된 DUT, 대용량 커패시터, 의도적인 전력 흡수(Sink) 평가는 현재 지원하지 않습니다.

## 2. 연결 준비

### 연결 방법 A: RS-232

- PC 쪽: USB-RS232 어댑터
- 장비 쪽: DB-9 Straight-through 배선
- 금지: Null-modem 케이블, TTL UART 케이블

연결 목록에는 Windows에서 확인된 포트가 `COM3 (RS-232)`처럼 표시됩니다. 목록에 아직 보이지 않으면 새로고침 후 `RS-232 포트 선택…`을 눌러 장치 선택 창에서 해당 COM 포트를 선택하세요. GPIB 주소가 목록에 있어도 이 RS-232 선택 항목은 항상 표시됩니다.

FTDI 칩 자체가 필수는 아니지만, 어댑터가 실제 RS-232 전압 레벨을 지원해야 합니다.

### 장비 전면 설정

- Baud: 9600
- Data bits: 8
- Parity: None
- Stop bits: 1
- Flow Control: NONE
- 장비 응답 Terminator: CR, CR+LF, LF, LF+CR 중 하나(프로그램이 연결 시 자동 확인)

프로그램은 장비 명령 끝에 항상 CR을 전송합니다. 연결할 때는 먼저 출력을 OFF로 만든 상태에서 장비의 응답 종단문자를 자동 확인하므로 전면 Terminator 설정이 달라도 별도로 프로그램 설정을 바꿀 필요가 없습니다.

### 연결 방법 B: GPIB

- NI GPIB-USB-HS 또는 호환 NI-VISA 지원 어댑터
- PC에 NI-488.2와 NI-VISA 드라이버 설치
- 프로그램은 `GPIB0::2::INSTR` 같은 VISA 주소를 자동 검색해 목록에 표시
- GPIB 연결에서도 2/4-wire, Source V/I, 평가 모드, 그래프, XLSX와 안전 제한은 동일

RS-232와 GPIB의 차이는 연결 계층과 종단 처리입니다. 실제 측정 SCPI 명령, 데이터 해석, 출력 OFF 및 Compliance 안전 정지는 동일한 모듈을 사용합니다. 두 인터페이스를 동시에 제어하지 마세요.

## 3. 2-Wire와 4-Wire

- 4-Wire: 최초 기본값입니다. FORCE HI/LO와 SENSE HI/LO를 DUT 양단에 각각 연결합니다. 낮은 저항, 정확한 DUT 양단 전압, 리드선 전압 강하 보상이 필요할 때 사용합니다.
- 2-Wire: FORCE HI/LO만 사용합니다. SENSE 단자를 별도로 DUT에 연결하지 않습니다.

프로그램은 4-Wire에서 `:SYST:RSEN ON`, 2-Wire에서 `:SYST:RSEN OFF`를 전송하고 `:SYST:RSEN?`으로 실제 설정을 확인합니다. 배선 방식을 바꾸기 전에 반드시 출력을 끄고 DUT에서 케이블을 분리하세요.

## 4. 안전 제한

프로그램은 개별 입력값과 조합을 모두 검사합니다.

| 설정 | 허용 범위 |
|---|---|
| 전압 인가 | 프로그램 평가 범위 ±200 V 이하 |
| 전압이 ±21 V 이하 | Current Compliance 1.05 A 이하 |
| 전압 절대값이 21 V 초과 | Current Compliance 0.105 A 이하 |
| 전류 인가 | ±1.05 A 이하 |
| 전류가 ±0.105 A 이하 | Voltage Compliance 200 V 이하 |
| 전류 절대값이 0.105 A 초과 | Voltage Compliance 21 V 이하 |
| 모든 조건 | Source 값 × Compliance가 22 W 이하 |

Current Compliance는 최소 1 nA, Voltage Compliance는 최소 0.2 mV 이상으로 제한됩니다.

200 V/1 A는 장비의 nominal range이고, Source programming overrange를 포함한 장비의 기술적 한계는 210 V/1.05 A입니다. 하지만 210 V에서는 자동 OVP에 필요한 10 V 여유를 확보할 수 없으므로 이 프로그램은 전압 인가와 Voltage Compliance를 최대 200 V로 제한합니다. 200 V를 설정하면 프로그램 OVP는 210 V, 장비 OVP는 210 V 전체 범위로 적용됩니다.

인가값 또는 Compliance에 한계를 넘는 값을 입력하면 시작 버튼이 즉시 비활성화됩니다. 입력칸에서 포커스를 빼면 `장비 스펙 초과` 팝업에 프로그램 평가 전압 ±200 V, 전류 ±1.05 A, 최대 출력 22 W와 21 V 초과 시 최대 0.105 A 제한을 표시하고, 장비 기술 한계 210 V를 사용하지 않는 이유와 입력값→자동 조정값을 함께 안내합니다. 단일·시간·Sweep·사이클 단계 모두 같은 팝업과 제한을 사용하며, 평가 시작 직전에도 동일한 검사를 다시 수행합니다. 이전 버전에 저장된 설정은 화면을 열 때 안전 범위로 정리됩니다.

전류 인가 모드에서는 인가 전류와 Voltage Compliance 아래에 `제품 저항이 약 ○○ 이하이어야 합니다`라는 쉬운 참고값을 표시합니다. 계산식은 `|Voltage Compliance ÷ 인가 전류|`입니다. 예를 들어 0.01 A와 20 V를 설정하면 기준 저항은 약 2 kΩ이며, DUT와 배선의 합성 저항이 이를 초과하면 장비가 전압 Compliance에 도달해 실제 전류가 0.01 A보다 낮아질 수 있습니다.

전압 인가 모드에서도 `제품 저항이 약 ○○ 이상이어야 합니다`라는 쉬운 참고값을 표시합니다. 계산식은 `|인가 전압 ÷ Current Compliance|`입니다. 예를 들어 9 V와 0.01 A를 설정하면 기준 저항은 약 900 Ω이며, DUT와 배선의 합성 저항이 이보다 낮으면 장비가 전류 Compliance에 도달해 실제 전압이 9 V보다 낮아질 수 있습니다. 두 참고값 모두 배선·접촉저항·DUT의 비선형 특성을 제외한 이론값이며 측정값 자체를 보정하지 않습니다.

같은 참고 계산 카드 안에는 초보자용 전압·전류 설정 한도를 항상 함께 표시합니다. `0~21 V는 최대 약 1.05 A`, `21 V 초과~200 V는 최대 약 0.105 A` 두 구간으로만 단순화하고, 현재 설정 전압에 해당하는 행을 강조합니다. 전류 제한은 실제로 항상 흐르는 전류가 아니라 넘지 못하게 막는 안전 한도라는 설명과 현재 입력값의 허용 여부도 함께 표시합니다. 22 W 경계에서 필요한 미세 조정은 프로그램이 자동 계산합니다.

전압 인가 모드에서는 장비 OVP를 자동 적용합니다. `|설정 전압| + 10 V` 이상인 장비 지원 단계를 선택하며, 화면의 `현재 장비 OVP`에 실제 적용값을 표시합니다. Keithley 2400은 20/40/60/80/100/120/160 V/NONE 단계만 지원하므로 1 V와 10 V 설정은 20 V, 100 V 설정은 120 V, 200 V 설정은 `210 V 전체 범위`가 됩니다. 장비가 상태 워드 bit 4로 OVP 발생을 알리면 프로그램도 즉시 `OUTPUT OFF`하고 결과를 OVP로 기록합니다.

30 V 이상이 될 수 있는 설정은 고전압 주의 대상으로 취급합니다. 설정 화면에 최대 예상 전압, Current/Voltage Compliance, 자동 OVP 단계와 함께 접촉 금지·절연 지그/인터락·OUTPUT OFF 및 잔류전압 방전 확인 주의사항이 즉시 표시됩니다. 단일·시간·Sweep·사이클 모두 실제 설정 중 가장 높은 예상 전압을 기준으로 표시하며, 시작 직전에도 동일한 고전압 확인창을 다시 표시합니다. 프로그램 경고는 절연 커버, 인터락, 비상 차단 장치와 작업장 안전 절차를 대신하지 않습니다.

## 5. 기본 사용 순서

1. OUTPUT이 OFF인지 장비 전면에서 확인합니다.
2. DUT 정격, 극성, 2/4-wire 배선을 확인합니다.
3. 앱에서 Keithley 2400 카드를 엽니다.
4. 목록에서 올바른 COM 포트 또는 GPIB VISA 주소를 선택하고 디바이스 연결을 누릅니다.
5. 시스템 로그에 `KEITHLEY ... 2400` ID가 표시되고 상태가 준비로 바뀌는지 확인합니다.
6. Source V 또는 Source I를 선택합니다.
7. 인가값과 Compliance를 입력합니다.
8. 2-Wire 또는 4-Wire와 측정 속도를 선택합니다.
9. 단일, 시간, I-V Sweep 또는 사이클을 선택하고 세부 조건을 입력합니다.
10. 안전 확인 후 시작을 누릅니다.
11. 팝업의 조건을 다시 확인하고 체크박스를 선택한 후 출력을 시작합니다.
12. 이상 상태에서는 즉시 비상 출력 OFF를 누릅니다.

## 6. 자동 안전 정지

다음 경우 프로그램이 `:OUTP OFF`를 전송하고 평가를 끝냅니다. 통신이 유지되는 동안에는 `:OUTP?`로 실제 상태도 확인합니다. 확인 응답을 받지 못하면 녹색 OFF로 단정하지 않고 `OUTPUT ?`를 표시합니다.

- 상태 워드에서 Compliance 감지
- 사용자 정지
- 정상 평가 완료
- 통신 또는 파싱 오류
- 장비 연결 해제
- Home으로 이동

통신 케이블 자체가 빠지면 OFF 명령이 장비에 도달하지 못할 수 있습니다. 항상 장비 전면 OUTPUT 표시와 실제 DUT 상태를 함께 확인하세요.

## 7. 측정 데이터

그래프는 데이터 테이블 바로 위의 중앙 영역에 넓게 표시됩니다. 그래프 왼쪽 위의 Voltage, Current, Resistance 체크박스로 원하는 항목만 표시할 수 있으며, 선택된 항목의 선과 독립 Y축 눈금만 나타납니다. 결과를 선택하지 않으면 가장 최근 평가를 표시하고, 결과 표의 왼쪽 체크박스를 선택하면 해당 평가를 표시합니다. 여러 결과를 체크하면 선택된 결과를 모두 같은 축에 겹쳐 비교합니다. 이때 평가 결과마다 서로 다른 색상을 사용하고, 항목은 전압=실선·전류=파선·저항=점선으로 구분합니다. 그래프 상단의 제품명 범례 색상과 선택된 표 행의 왼쪽 색상선도 해당 평가의 그래프 색상과 같습니다. 시간·단일·사이클 평가는 X축이 경과시간이고, 선택 결과가 모두 Sweep일 때는 X축이 Source 설정값입니다.

화면 표는 Raw 샘플을 한 줄씩 나열하지 않고 평가 1회당 결과 1행을 표시합니다. 결과에는 평가일(표시는 월/일), 제품명, 모드, 배선, Source 조건, 최대 절대 전압, 최대 절대 전류, 전류 평균값, 최대 절대 저항, 측정 수, 평가 시간, 상태가 포함됩니다. 음전압·음전류 평가도 크기를 올바르게 비교하도록 최대 전압과 최대 전류는 절댓값 기준이며, 전류 평균값은 해당 평가의 모든 유효 Raw 전류를 부호를 포함해 산술평균한 값입니다. 제품명은 테두리가 있는 입력 칸에서 측정 후에도 수정할 수 있으며, 수정 내용은 해당 평가의 모든 Raw 샘플과 그래프 범례에 반영됩니다.

`대시보드 XLSX 저장`은 프로그램에 포함된 Keithley 2400 전용 Excel 템플릿을 복사한 뒤 선택 결과로 내용을 교체해 통합문서 하나를 만듭니다. 저장 시점의 프로그램 언어를 그대로 적용하므로, 한국어 UI에서는 `대시보드` 시트와 한국어 제목·표·Raw Data 헤더가 생성되고 영문 UI에서는 `Dashboard` 시트와 영문 제목·표·Raw Data 헤더가 생성됩니다. 평가 중간에 언어를 바꾸더라도 실제 XLSX 저장 버튼을 누르는 시점의 언어가 기준입니다. 템플릿에 들어 있던 예시 데이터는 남기지 않습니다.

1번 시트는 상단에 전압·전류·저항 항목 체크 셀, 샘플별 색상선과 샘플명만 표시하는 범례, 비교 그래프를 차례로 배치하고, 그 아래에 샘플 목록을 평가별 한 행으로 나열합니다. 결과를 하나 선택하면 해당 평가만 표시되고, 여러 결과를 선택하면 선택한 평가가 서로 다른 색상으로 함께 표시됩니다. 샘플 목록 맨 왼쪽 체크 셀을 해제하면 해당 평가만 그래프에서 숨겨집니다. 범례에는 전류·저항 계열명이 중복 표시되지 않으며 샘플마다 한 항목만 표시됩니다. 전압은 실선, 전류는 파선, 저항은 점선으로 구분합니다. 대시보드의 샘플 체크 셀과 전압·전류·저항 체크 셀을 변경하면 체크된 항목만 표시되도록 숨김 `_ChartData` 시트의 수식이 다시 계산됩니다. 차트는 이미지가 아니라 Excel 기본 산점도 차트이며 2번 시트의 Raw Data 숫자 셀을 참조하므로 Raw Data 값을 수정해도 반영됩니다. 선택이 없으면 전체 평가를 내보냅니다.

2번 `Raw Data` 시트는 선택한 평가만 왼쪽부터 A:D, F:I, K:N 순서로 차례대로 새로 배치합니다. 각 평가 블록 상단에는 샘플명, 테스트 방법, 평가 시각, 인가 설정, Compliance와 상태를 정리하고, 8행 헤더 아래 9행부터 `시간 → 전압 → 전류 → 저항` 순서의 실제 숫자 셀을 저장합니다. 여러 평가의 측정 수가 달라도 각 블록은 독립적으로 아래 방향으로 기록되므로, Excel에서 원하는 평가의 네 열을 선택해 추가 그래프를 만들 수 있습니다. 저장은 우선 프로그램/서버 폴더에 시도하고, 서버 저장 기능이 없는 환경에서는 브라우저 다운로드로 전환됩니다.

그래프 우측 하단의 `그래프 이미지 저장`을 누르면 현재 화면에 표시된 평가·선택 항목·그래프 범례가 PNG 이미지로 저장됩니다.

평가가 완료되면 요약 결과와 그래프·Raw Data XLSX 복원에 필요한 원시 샘플이 `Keithley2400_eval_data.json`에 자동으로 누적 저장됩니다. 다시 실행하면 이 목록을 자동으로 불러옵니다. `목록 저장`은 현재 목록을 즉시 저장하고, `목록 내보내기`는 다른 컴퓨터로 옮길 수 있는 JSON 파일을 만듭니다. `목록 가져오기`는 기존 목록을 지우지 않고 추가·병합하며, 이미 있는 동일 평가 ID는 중복으로 건너뜁니다.

장비가 `±9.9E37` 계열 값을 보내면 Over Flow이며 정상 숫자로 저장하지 않습니다. 저항은 측정 전압을 측정 전류로 나누어 계산합니다.

### 사이클 설정 방법

1. 평가 모드에서 사이클을 선택합니다.
2. 인가값, Compliance, 유지시간을 입력하고 단계 추가를 누릅니다.
3. 필요한 단계 수만큼 반복하고, 표 안의 값을 직접 수정하거나 불필요한 단계를 삭제합니다.
4. 반복 횟수와 측정 간격을 입력하고 총 예정시간을 확인합니다.
5. 안전 확인 후 시작을 누릅니다.

사이클 단계가 바뀔 때 프로그램은 인가값을 먼저 0으로 내린 후 새 Compliance와 새 인가값을 적용합니다. 각 단계의 설정이 장비 정격 또는 22 W 제한을 넘으면 시작할 수 없습니다.

## 8. 첫 실장비 확인 권장 조건

- 비유도성 더미 저항 사용
- Source V 1 V
- Current Compliance 10 mA
- 4-Wire 배선
- MED (1 NPLC)
- 단일 측정 1회

전면 표시값, 시스템 로그의 원시 응답, 프로그램의 V/I/R 값을 비교한 뒤 전압과 전류를 단계적으로 올리세요.

## 9. 문제 해결

### 연결 후 준비 상태가 되지 않음

- RS-232 사용 시 장비 인터페이스, 9600, 8-N-1, Flow Control NONE, Straight-through DB-9 확인
- GPIB 사용 시 장비 주소와 프로그램 목록의 주소가 같은지, NI-488.2/NI-VISA가 설치됐는지 확인
- NI MAX나 다른 프로그램이 같은 COM/GPIB 세션을 사용 중이지 않은지 확인
- 시스템 로그의 `*IDN?` 응답과 SCPI 오류 확인

### 4-Wire에서 값이 이상함

- FORCE와 SENSE의 HI/LO 극성이 맞는지 확인
- Sense 리드가 DUT 단자에서 빠지지 않았는지 확인
- 2-Wire 배선인데 화면만 4-Wire로 선택하지 않았는지 확인

프로그램은 평가 시작 시 전압과 전류를 모두 실제로 측정하도록 설정하고, 장비의 2/4-Wire 적용값을 다시 확인합니다. 측정 중에는 샘플 사이에도 출력을 유지하며 평가 종료·중지·오류 시 OFF합니다. 그래프에서 읽지 못한 구간은 선이 끊기고, 측정점이 하나뿐이면 점으로 표시됩니다.

4-Wire는 리드선 전압 강하를 보상하는 방식입니다. 케이블이나 지그의 누설전류까지 자동으로 없애는 기능은 아닙니다. 전류가 아주 작아 0 근처에서 부호가 바뀌면 `전압 ÷ 전류`로 계산한 저항이 크게 흔들릴 수 있습니다. 프로그램은 이 값을 임의로 0으로 만들거나 설정 전류로 바꾸지 않습니다.

이상이 계속되면 같은 순간의 장비 전면 V/I, 프로그램 V/I, 시스템 로그의 `[2400 READ]` 원문을 비교하세요. 로그 원문은 전압(V), 전류(A), 장비 시간(s), 상태 순서입니다. 전면값도 이상하면 배선·접촉·제품 상태를 먼저 확인하고, 전면값은 정상인데 프로그램만 다르면 해당 원문과 설정값을 함께 확인합니다.

### Compliance가 바로 발생함

- DUT 저항 또는 극성이 예상과 다른지 확인
- Current/Voltage Compliance가 너무 낮은지 확인
- DUT 단락 여부 확인
- Source V와 Source I 모드를 반대로 선택하지 않았는지 확인
