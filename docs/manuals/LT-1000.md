# ChemInstruments LT-1000 (Loop Tack 시험기) — 사용 매뉴얼

루프 형태의 시료를 접촉·분리하며 점착력을 측정하는 시험기입니다. ✅ 실기 동작 확인 완료.

## 1. 통신 사양

| 항목 | 값 |
|---|---|
| Baud Rate | 9600 |
| Data / Parity / Stop | 8 / None / 1 |
| Flow Control | None |
| 특이사항 | 연결 시 DTR/RTS 신호 HIGH 설정 (앱이 자동 처리) |

> ⚠ LT-1000은 능동 측정이 아닌 **수동 전송 방식**입니다.
> 장비에서 Print 조작을 해야 데이터가 PC로 전송됩니다.

## 2. 데이터 전송 방법 (📋 앱 내 팝업 가이드 동일)

1. LT-1000에서 **Select** 버튼으로 데이터 메뉴로 이동
2. 🔴 **Run 상태(빨간 LED)** 에서 평가를 진행
3. **Print** (🔴) → **Enter** → **Enter**
4. 약 3~5초 후 타이머가 종료되면 데이터가 앱에 **자동 기록**됨 (녹색 표시)

## 3. 로드셀 캘리브레이션 (⚖️ 앱 내 팝업 가이드 동일)

1. 로드셀을 **최상단으로 이동** 후 **고정핀 체결**
2. **Select + Enter 3초 이상** → 🔴 **Setup** → **Enter**
3. 디스플레이에 `LC 0.000` 확인 → **Enter** (무부하 0점 교정)
4. 디스플레이에 `HC 1000` 표시 → **1 kg 분동**을 올린 후 **Enter**
5. 추 제거 → 로드셀 파지 → 고정핀 해제 → 조심히 내려놓기

## 4. ST FULL 해결 방법 (⚠️ 앱 내 팝업 가이드 동일)

장비 메모리(20개)가 가득 차면 `ST FULL` 오류가 발생합니다.

1. **Select** → 🔴 **Print** → **▲ ×2** → **DL** → **Enter**
2. **Select + Enter 3초 이상** → 초기화 완료
3. 다시 평가 시작 (녹색 표시)

> 💡 헤더의 시험 번호가 20에 도달하면 앱이 자동으로 메모리 풀 경고 팝업을 띄웁니다.

## 5. 측정값 계산

- 샘플링: 400 Hz, 속도 5.08 mm/s (12 in/min)
- Peak(gf), Avg, Work(mJ), 실패 모드(Snap / 표준 / Creep — 피크 위치 비율로 판정)
- 유효 기준: 데이터 100포인트 이상 + Peak ≥ 2.0 gf

## 6. 문제 해결

| 증상 | 해결 |
|---|---|
| Print 해도 데이터 안 옴 | 케이블 확인, 재연결 (DTR/RTS는 앱이 자동 설정) |
| ST FULL 표시 | 위 4번 절차로 장비 메모리 초기화 |
| 값이 너무 작아 무시됨 | Peak 2.0gf 미만은 무효 처리 — 시료 부착 상태 확인 |
