# ChemInstruments PT-2000 (Probe Tack 시험기) — 사용 매뉴얼

프로브를 시료에 접촉 후 떼어내며 점착력(Tack)을 측정하는 시험기입니다.

## 1. 연결 방식 — WebHID (시리얼 아님!)

| 항목 | 값 |
|---|---|
| 인터페이스 | **WebHID** (USB 직접 연결) |
| 장치 식별자 | VID `0x04D8`, PID `0xF47E` (Microchip) |
| 시리얼 케이블 | 불필요 |

> 💡 다른 계측기와 달리 COM 포트가 아닌 **HID 장치 선택 팝업**으로 연결합니다.

## 2. 앱 사용 절차

1. 런처에서 **PT-2000 Probe Tack** 카드 클릭
2. USB 케이블로 PT-2000을 PC에 직접 연결
3. 사이드바의 **연결** 버튼 클릭 → HID 장치 선택 팝업에서 PT-2000 선택
4. 장비에서 측정을 실행하면 결과가 자동으로 기록됨
   - Peak / Avg / Min / 표준편차 / Work(J) / 실패 모드가 함께 계산됨
5. 측정 후 **프로브 클리닝 확인**(Proceed) 안내가 나타나면 프로브를 닦은 뒤 진행
   (최소 20초 대기 필요)
6. 그룹 개수 ≥ 2로 설정하면 우측에 Peak(gf) 수염차트가 표시됨

## 3. 그래프 보기

- **곡선 보기**: 측정 직후 또는 테이블에서 행 1개만 체크하면 해당 측정의 힘-시간 곡선 표시
- **수염차트 보기**: 행 여러 개 체크 또는 체크 해제 상태에서 그룹별 분포 표시

## 4. Excel 내보내기

**Excel 저장** 버튼 → `.xlsx` 파일 생성 (2개 시트):

| 시트 | 내용 |
|---|---|
| 요약 결과 | No / 샘플명 / Peak / Avg / Min / 표준편차 / Work / 실패 모드 |
| 샘플별 Raw Data | 샘플별 Time(s) / Disp(mm) / Force(gf) 원본 곡선 데이터 |

⚠ Excel 내보내기는 CDN(ExcelJS)을 사용하므로 인터넷 연결이 필요합니다.

## 5. 측정 무효(ABORT) 기준

- 데이터 포인트 1000개 미만, 또는
- Peak < 1.0 gf

인 경우 측정이 무효 처리됩니다. 프로브 접촉 상태를 확인하세요.

## 6. 문제 해결

| 증상 | 해결 |
|---|---|
| HID 팝업에 장치 없음 | USB 케이블 재연결, 장비 전원 확인 |
| 측정이 계속 무효 처리 | 프로브가 시료에 제대로 접촉하는지 확인 |
| Proceed 버튼 비활성 | 프로브 클리닝 최소 대기 시간(20초) 경과 후 활성화됨 |
