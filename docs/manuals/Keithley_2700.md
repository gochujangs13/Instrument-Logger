# Keithley 2700 (멀티미터) — 사용 매뉴얼

4선식(4-Wire) 정밀 저항 측정이 가능한 멀티미터입니다. ✅ 실기 동작 확인 완료.

## 1. 통신 사양

| 항목 | 값 |
|---|---|
| Baud Rate | 9600 |
| Data / Parity / Stop | 8 / None / 1 |
| 종단문자 | CRLF (`\r\n`) |
| 폴링 | `:READ?` — 500ms 간격 자동 |

## 2. 계측기 측 준비

1. 본체 메뉴에서 **RS-232 인터페이스** 선택
2. 통신 속도 9600 bps, 8N1 설정
3. USB↔RS-232C 케이블로 PC와 연결

## 3. 연결 시 자동 초기화

연결하면 앱이 자동으로 초기화 시퀀스를 전송합니다 (약 3초 소요):

```
*RST → *CLS → SYST:REM → *CLS → SENS:FUNC "FRES" → *CLS
```

- `*RST` 완료까지 약 1.2초가 걸리므로 명령이 시간차를 두고 분산 전송됩니다.
- 에러 큐 누적(-363 → -350 overflow)을 막기 위해 **30초마다 `*CLS`가 자동 전송**되고, 비정상 응답이 10회 연속되면 즉시 큐를 클리어합니다.

## 4. 앱 사용 절차

1. 런처에서 **Keithley 2700** 카드 클릭
2. 연결 → 약 3초 후 자동 초기화 완료, 측정 시작
3. 사이드바에서 **측정 방식**(4-Wire/2-Wire), **NPLC**, **테스트 방법** 설정
4. **기록 시작** → 그리드에 측정값 자동 기록
5. **복사** 또는 **CSV 저장**으로 내보내기

## 5. 사이드바 설정

| 항목 | 설명 |
|---|---|
| 측정 방식 | 4-Wire(FRES, 정밀) / 2-Wire(RES) |
| NPLC | 적분 사이클 수 — 높을수록 정밀·느림 (FAST/MED/SLOW) |
| 테스트 방법 | 그룹 크기·컬럼 자동 설정 |

## 6. 표시값 해석

- **Over Flow**: 응답이 `9.90E+37` — 프로브 미연결 또는 측정 범위 초과.
  오버플로우 값은 자동 기록에서 제외되므로 기록이 오염되지 않습니다.

## 7. 문제 해결

- **"Over Flow" 지속**: 프로브를 시료에 제대로 접촉시키세요
- **연결 직후 값 없음**: 초기화 3초 대기 — 정상 동작입니다
- **-350 에러 발생**: 앱이 자동으로 에러 큐를 관리하지만, 지속되면 장비 전원을 껐다 켠 후 재연결
