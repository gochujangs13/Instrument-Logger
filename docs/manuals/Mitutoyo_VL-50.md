# Mitutoyo VL-50 (두께계) — 사용 매뉴얼

시료 두께를 mm 단위 소수점 5자리까지 측정하는 리니어 게이지입니다. ✅ 실기 동작 확인 완료.

## 1. 통신 사양 — ⚠ 다른 계측기와 다름!

| 항목 | 값 |
|---|---|
| Baud Rate | 9600 |
| Data Bits | **7** (8 아님!) |
| Parity | **Even** (None 아님!) |
| Stop Bits | **2** (1 아님!) |
| 종단문자 | CRLF (`\r\n`) |
| 폴링 | `GA01\r\n` — 300ms 간격 (필수 — 없으면 응답 없음) |

> 🔴 **유일하게 7-E-2 설정을 쓰는 장비**입니다. 앱이 자동으로 올바르게 연결하므로
> 사용자가 별도 설정할 필요는 없지만, 다른 프로그램으로 연결할 때는 반드시 7E2로 설정하세요.

## 2. 계측기 측 준비

1. 본체 후면 RS-232C 포트에 케이블 연결
2. 본체 통신 설정: 9600 bps / 7 data bits / Even parity / 2 stop bits
3. 연결 시 앱이 자동으로 `CS\r\n`(에러 클리어)을 전송

## 3. 앱 사용 절차

1. 런처에서 **Mitutoyo VL-50** 카드 클릭
2. 연결 → 300ms마다 두께값이 소수점 5자리(mm)로 자동 갱신
3. 사이드바에서 **테스트 방법**(MSL-2, ETM-7 등) 선택 — 기본값 MSL-2, 그룹당 6개
4. **기록 시작** → 그리드에 두께값 자동 기록
5. **복사** 또는 **CSV 저장**

## 4. 문제 해결

- **값이 전혀 안 옴**: 대부분 시리얼 설정 문제 — 이 장비는 7E2입니다.
  앱은 자동으로 7E2로 연결하므로, 그래도 안 오면 케이블/본체 통신 설정 확인
- **측정부가 움직이지 않음**: 본체 스핀들이 눌려 있는지, 측정 대상이 올려져 있는지 확인
