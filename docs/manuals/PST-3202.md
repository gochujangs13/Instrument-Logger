# GW Instek PST-3202 (3채널 DC 전원공급기) — 초보자용 상세 매뉴얼

> 이 매뉴얼은 전원공급기를 처음 사용하는 분도 따라할 수 있도록 기초 개념부터 설명합니다.
> 이미 익숙하신 분은 [4. 빠른 시작](#4-빠른-시작-5분-요약)부터 보세요.

---

## 1. 이 장비는 무엇인가요?

**PST-3202는 "전기를 공급하는 장비"입니다.**

건전지가 1.5V의 전기를 내보내듯, 이 장비는 **원하는 전압과 전류를 정밀하게 만들어**
시료(샘플)에 공급합니다. 건전지와 다른 점은:

- 전압을 **0V부터 원하는 값까지 자유롭게** 설정할 수 있고
- 전류가 너무 많이 흐르지 않도록 **한계를 걸 수 있으며**
- **3개의 독립된 출력(채널)** 을 동시에 쓸 수 있다는 것입니다.

### 채널별 사양 (외울 필요 없음 — 앱이 자동으로 막아줍니다)

| 채널 | 최대 전압 | 최대 전류 | 주 용도 |
|---|---|---|---|
| CH1 | 32 V | 2 A | 샘플 1 |
| CH2 | 32 V | 2 A | 샘플 2 |
| CH3 | 6 V | 5 A | 저전압 샘플 |

### 꼭 알아야 할 두 가지 개념

| 용어 | 쉬운 설명 |
|---|---|
| **전압 (V, 볼트)** | 전기를 "미는 힘". 수도관의 수압과 같습니다. |
| **전류 (A, 암페어)** | 실제로 "흐르는 전기의 양". 수도관에 흐르는 물의 양과 같습니다. |

> 💡 **전류 제한이 왜 필요한가요?**
> 시료에 이상이 생겨(합선 등) 전기가 갑자기 많이 흐르면 시료가 타거나 위험할 수 있습니다.
> "전류 제한"을 걸어두면 그 이상은 절대 흐르지 않아 **시료와 장비를 보호**합니다.

## 2. 장비 연결하기

### 준비물
- PST-3202 본체 + 전원 케이블
- USB↔RS-232C 변환 케이블
- 시료 연결용 바나나 케이블 (빨강 = +, 검정 = −)

### 연결 순서

1. PST-3202 뒷면 RS-232 포트에 케이블을 꽂고 PC USB에 연결
2. PST-3202 전원 ON
3. 앱 실행 → 런처에서 **PST-3202** 카드 클릭
4. 상단 **[연결 안됨]** 버튼 클릭 → COM 포트 선택 → **연결**
5. 상단이 **[연결됨]**(초록)으로 바뀌면 준비 완료

> ⚠ 포트 목록에 아무것도 없으면 USB-Serial 드라이버(CH340/FTDI 등)를 설치하세요.

### 시료 연결

- 시료의 (+)를 채널의 빨간 단자에, (−)를 검정 단자에 연결
- **극성(+/−)을 반대로 연결하지 않도록 주의**

## 4. 빠른 시작 (5분 요약)

**예: 샘플에 12V, 최대 0.5A로 전기를 공급하고 싶을 때**

1. 연결 (위 2번)
2. CH1 카드의 **전압 설정**에 `12` 입력 → **Enter**
3. **전류 제한**에 `0.5` 입력 → **Enter**
4. 하단의 **출력 ON** 버튼 클릭
5. LED 디스플레이에 실제 전압·전류가 표시되고, 그래프가 그려지기 시작
6. 끝나면 **출력 OFF** → 평가 기록이 자동 저장됨

> 💡 **값 입력 시 걱정하지 마세요**: 최대값(32V)을 넘는 값을 입력하면
> 앱이 **자동으로 최대값으로 조정**하고 입력칸 아래에
> `↩ 최대 32V로 자동 조정됨` 안내가 표시됩니다. 잘못된 값으로 장비가 손상될 일이 없습니다.

## 5. ⚡ 전압 제어 vs 🔋 전류 제어 — 무엇을 고르나요?

| 모드 | 동작 | 언제 사용? |
|---|---|---|
| ⚡ **전압 제어 (CV)** | 설정한 전압을 일정하게 유지. 전류는 시료에 따라 자연히 결정됨 | **대부분의 경우 이것** (기본값) |
| 🔋 **전류 제어 (CC)** | 설정한 전류를 일정하게 유지. 전압은 자동으로 변함 | 일정 전류가 필요한 특수 시험 (LED, 도금 등) |

- 전류 제어 모드에서는 전압이 채널 최대값으로 걸리고, 전류만 목표값에 고정됩니다.
- 헷갈리면 **⚡ 전압 제어**를 쓰세요.

## 6. 📌 고정값 모드 vs 🔄 사이클 모드

### 고정값 모드 (기본)
설정한 전압·전류를 **계속 유지**합니다. 대부분의 평가에 사용합니다.

### 사이클 모드
**시간에 따라 값을 자동으로 바꿔가며** 공급합니다.

예: "5V로 10초 → 10V로 20초 → 0V로 5초"를 3회 반복

1. 채널 카드 하단의 **🔄 사이클** 탭 클릭 → 화면 하단에 사이클 편집기가 열림
2. 전압, 전류, 시간(초)을 입력하고 **➕ 단계 추가**
3. 필요한 만큼 단계를 추가 (표에서 직접 수정·삭제 가능)
4. **반복 횟수** 설정 → 예상 소요 시간이 자동 계산됨
5. **▶ CH시작** (해당 채널만) 또는 **▶ 전체 시작** (사이클 설정된 모든 채널 동시)

> 💡 사이클 편집기의 입력 범위도 자동 검증됩니다. 예를 들어 3채널 동기화 중이면
> 전압 범위가 `(0–6V)`로 표시되고 초과 입력 시 자동 조정됩니다.

## 7. 채널 동기화 — 같은 조건으로 여러 샘플 동시 평가

**"샘플 2개(또는 3개)에 완전히 같은 조건을 걸고 싶다"** 면 동기화를 쓰세요.

### CH1 ↔ CH2 동기화

1. CH1과 CH2 카드 사이의 **동기화** 토글을 ON
2. 이후 CH1의 전압/전류를 바꾸면 **CH2에 자동으로 복사**됩니다
3. 동기화 중에는 점이 흘러내리는 애니메이션이 표시됩니다

### CH3까지 동기화 (3채널 동시)

1. CH1↔CH2 동기화가 ON인 상태에서 **CH3 동기화** 토글이 나타남
2. ON 하면 CH3도 CH1과 같은 값으로 묶입니다. 단, CH3 사양에 맞춰:
   - **전압 최대 6V** (CH3의 물리적 한계)
   - **전류 최대 2A** (3채널 통일을 위한 제한)
3. CH1 전압이 6V를 넘는 상태에서 켜면 **세 채널 모두 6V로 자동 조정**되고
   `↩ 3채널 최대 전압(6V)으로 전체 채널 조정됩니다` 안내가 표시됩니다
4. CH3 카드의 입력은 잠기고 스펙 표시가 `0–6 V / 0–2 A (동기화)`로 바뀝니다

> ⚠ **병렬/직렬 트래킹과 혼동하지 마세요!**
> 사이드바의 병렬/직렬 트래킹은 **물리적 배선을 바꿔 출력을 합치는 기능**으로,
> 독립된 샘플 여러 개를 동시 평가하는 용도가 아닙니다.
> 여러 샘플 동시 평가에는 반드시 **독립 모드 + 동기화 토글**을 사용하세요.

## 8. 보호 기능 — OCP와 OVP

| 기능 | 풀네임 | 하는 일 |
|---|---|---|
| **OCP 보호** | Over Current Protection (과전류 보호) | 설정한 전류 제한을 초과하면 출력을 자동 차단 |
| **OVP 설정** | Over Voltage Protection (과전압 보호) | 출력 전압이 설정한 한계를 넘으면 출력을 자동 차단 |

- OCP: 체크박스로 ON/OFF
- OVP: 버튼 클릭 → 한계 전압 입력 팝업

> 💡 처음 사용하는 시료라면 OCP를 켜두는 것을 권장합니다.

## 9. 입력값 검증 — 앱이 실수를 막아주는 방식

| 입력 상황 | 앱의 동작 |
|---|---|
| 최대값 초과 (예: CH1에 40V) | 즉시 최대값으로 자동 수정 + `↩ 최대 32V로 자동 조정됨` 표시 |
| 3채널 동기화 중 CH1에 6V 초과 | `↩ 3채널 최대 전압(6V)으로 조정됩니다` 표시, Enter 시 6V로 적용 |
| 음수 입력 | `⚠ 0V 이상 입력` 경고 표시 |
| 정상 범위 | 안내 없음, 그대로 적용 |

전류 입력값은 항상 소수점 3자리로 표시됩니다 (예: `2` 입력 → `2.000`).

## 10. 실시간 그래프와 평가 기록

- **출력 ON** 하면 그래프가 시작되고 채널별 전압(실선)·전류(점선)가 실시간 표시됩니다
- 사용하지 않는 채널("사용" 토글 OFF)은 그래프에 나타나지 않습니다
- **출력 OFF** 하면 해당 세션이 **평가 기록으로 자동 저장**됩니다
- 저장된 기록은 우측 패널에서 확인·CSV 내보내기 가능합니다
- **자동 정지**: 설정 시간 경과 후 출력을 자동으로 끄는 기능 (장시간 평가용)

### 10-1. 평가 목록을 다른 컴퓨터로 옮기기

측정 기록은 이 컴퓨터에 자동 저장되지만, **다른 컴퓨터에서도 이전 기록을 보고 싶다면**
Data Table 영역의 두 버튼을 사용하세요.

| 버튼 | 동작 |
|---|---|
| **📤 목록 내보내기** | 현재 평가 기록 전체를 `PST3202_records_날짜시간.json` 파일로 다운로드 |
| **📂 목록 가져오기** | 파일을 선택하면 그 안의 기록을 **현재 목록에 추가**합니다 |

**사용 순서 (예: 컴퓨터 A → 컴퓨터 B로 이동)**

1. 컴퓨터 A에서 **📤 목록 내보내기** 클릭 → JSON 파일이 다운로드됨
2. USB 등으로 이 파일 하나만 컴퓨터 B로 옮김
3. 컴퓨터 B의 PST-3202 화면에서 **📂 목록 가져오기** 클릭 → 방금 옮긴 파일 선택
4. 컴퓨터 B의 기존 기록 뒤에 가져온 기록이 추가됨

> 💡 **같은 기록을 두 번 가져와도 안전합니다.** 측정 시각(타임스탬프)이 완전히 같은 기록은
> 자동으로 건너뛰고 중복 추가하지 않습니다. 가져오기 완료 시 "N개 추가됨, M개는 중복이라 제외됨"
> 안내가 표시됩니다.

가져온 기록도 일반 기록과 똑같이 취급되므로, 체크박스로 선택해 **📥 Raw Data (xlsx)**로
엑셀 내보내기하는 것도 그대로 가능합니다.

## 11. 자주 묻는 질문 (FAQ)

**Q. 출력을 켰는데 전류가 0으로 나와요.**
A. 정상일 수 있습니다. 전류는 시료가 연결되어 실제로 전기가 흘러야 표시됩니다.
시료 연결과 극성(+/−)을 확인하세요.

**Q. 전압을 입력했는데 적용이 안 돼요.**
A. 입력 후 **Enter**를 눌러야 적용됩니다. 입력칸 아래 경고 메시지도 확인하세요.

**Q. CH2 설정이 안 바뀌어요.**
A. CH1↔CH2 동기화가 ON이면 CH2는 CH1을 따라갑니다. 개별 설정하려면 동기화를 끄세요.
병렬/직렬 트래킹 모드에서도 일부 채널이 잠깁니다.

**Q. 설정한 전류 제한보다 전류가 안 올라가요.**
A. 그것이 정상입니다 — "전류 제한"은 그 이상 흐르지 못하게 막는 안전장치입니다.
더 필요하면 제한값을 올리세요 (최대 2A/5A).

**Q. 출력 OFF 상태인데 LED에 값이 안 나와요.**
A. 출력이 꺼져 있으면 측정 폴링도 멈춥니다 (불필요한 통신 방지). 정상 동작입니다.

**Q. 3채널 동기화를 켰더니 전압이 6V로 떨어졌어요.**
A. CH3의 물리적 최대 전압이 6V라서, 3채널을 같은 값으로 묶으려면 6V 이하만 가능합니다.
6V 초과가 필요하면 CH3 동기화를 끄고 CH1↔CH2만 동기화하세요 (32V까지 가능).
