# SP-2100 / TL-2200 (박리·인장 시험기) — 사용 매뉴얼

점착 테이프 및 필름의 박리력(Peel)·인장력을 측정하는 시험기입니다. ✅ 실기 동작 확인 완료.

---

## 1. 통신 사양 — 모델별로 다름

| 항목 | SP-2100 | TL-2200 |
|---|---|---|
| **Baud Rate** | **57600** (권장) | **38400** (기본) |
| **Data / Parity / Stop** | 8 / None / 1 | 8 / None / 1 |
| **종단문자** | CR (`\r`) | CR (`\r`) |
| **폴링** | 없음 (자율 전송) | `R\r` — 300ms 주기 |

사이드바 상단 **장비 모델** 드롭다운에서 모델을 선택하면 통신 속도와 파싱 방식이 자동 변경됩니다.

---

## 2. 앱 사용 절차

1. 런처에서 **SP-2100 / TL-2200** 카드 클릭
2. 사이드바에서 **장비 모델**, **통신 속도**, **Test Speed**, **Initial Delay**, **Averaging Time**, **그룹당 개수** 설정 (설정값은 브라우저에 자동 저장되어 재접속 시 자동 복원)
3. `디바이스 연결` 클릭 후 COM 포트 선택
4. **장비에서 측정을 실행**하면 결과가 자동으로 테이블에 추가되고 파형 그래프가 그려짐
5. 테이블의 **제품명** 칸을 클릭해 제품명을 언제든 수정 가능 (기본 이름: `제품 N`)
6. **덮어쓰기 기능**: 테이블에서 체크박스를 1개만 선택하고 다시 측정하면 해당 행에 새 결과가 덮어써집니다.

---

## 3. 웹 화면 차트 기능

- **힘-시간 파형 그래프 (좌측 70%)**:
  - 측정 완료 시 힘-시간 전체 곡선이 표시됩니다.
  - **복수 마우스 드래그 구간 분석**: 원하는 구간을 여러 번 드래그하면 기존 선택을 유지한 채 `구간 #1`, `구간 #2`처럼 누적됩니다. 각 구간의 평균·최소·최대와 시간 범위가 칩으로 표시되고, 그래프에는 구간별 색상 음영이 표시됩니다.
  - 여러 구간을 선택하면 그래프 상단에 **통합 평균·통합 최소·통합 최대·총 포인트 수**가 표시됩니다. 겹치는 구간의 포인트는 중복 계산하지 않습니다.
  - `✕ 해제`로 전체 구간을 지우거나 각 구간의 `✕`로 하나만 제거할 수 있습니다.
  - `✓ 적용하기`를 누르면 선택 구간 통계가 현재 측정 행의 AVG/KP/VAL에 반영됩니다. `↺ 원본 복구`로 장비 원본값으로 되돌릴 수 있습니다.
- **AVG 분포 수염차트 (우측 30%)**:
  - 그룹별 또는 체크한 행들의 공식 장비 측정값(AVG) 분포를 박스-수염 차트로 표시합니다.
- **Y축 스케일 조정**:
  - 차트 좌측 Y축에 마우스를 올리면 숫자 입력창이 나타나며, 수동으로 상한/하한을 고정할 수 있습니다 (`↺` 클릭 시 자동 스케일 복귀).

## 4. 대시보드 및 Raw Data XLSX 저장 기능

우측 상단 **`XLSX 저장`** 버튼을 누르면 키슬리 2400 수준의 인터랙티브 Excel 파일이 자동 생성됩니다.

1. **Sheet 1 (`대시보드`)**:
   - **박리력 비교 그래프 (Force-Time)**: Excel 네이티브 분산형 차트로, 데이터 포인트가 1/3 크기(`size: 2`, `1.0pt`)로 최적화되어 깔끔하게 표시됩니다.
   - **체크박스 드롭다운 (`☑` / `☐`)**: 첫 번째 열의 체크박스 드롭다운을 통해 차트에 표시할 시료를 개별 또는 다중으로 켜고 끌 수 있습니다.
   - **📍 구간 분석 컨트롤 바**: 표 상단의 `시작 시간 (s)`과 `종료 시간 (s)` 숫자를 변경하면, 표의 `구간 평균 (g)`, `구간 최소 (g)`, `구간 최대 (g)` 열이 엑셀 네이티브 수식(`AVERAGEIFS`, `MINIFS`, `MAXIFS`)을 통해 실시간으로 자동 재계산됩니다.
2. **Sheet 2 (`Raw Data`)**:
   - 모든 시료의 시험 조건 헤더와 초 단위 시간(s), 힘(g) 원시 측정 데이터 전체가 기록됩니다.
3. **Sheet 3 (`_ChartData`, 숨김)**:
   - 대시보드 체크박스 상태에 따라 차트에 데이터를 동적으로 공급하는 수식 시트입니다.

## 5. 저장 경로 안내

- **개발 서버 실행 시**: 프로그램 루트 폴더 바로 아래 (`SP2100_Dashboard_....xlsx`)
- **EXE 단독 실행 시**: `3M_Instrument_Logger.exe` 파일이 위치한 폴더
- **서버 미실행 폴백 시**: 웹 브라우저의 기본 `다운로드(Downloads)` 폴더
- 저장 시 화면 좌측 하단 **SYSTEM LOG**에 실제 저장된 전체 파일 경로가 안내됩니다.
