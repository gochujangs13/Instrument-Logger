# SP-2100 / TL-2200 (박리·인장 시험기) — 사용 매뉴얼

점착 테이프의 박리력(Peel)·인장력을 측정하는 시험기입니다. ✅ 실기 동작 확인 완료.

## 1. 통신 사양 — 모델별로 다름

| 항목 | SP-2100 | TL-2200 |
|---|---|---|
| Baud Rate | **57600** | **38400** |
| Data / Parity / Stop | 8 / None / 1 | 8 / None / 1 |
| 종단문자 | CR (`\r`) | CR (`\r`) |
| 폴링 | `R\r` — 300ms | `R\r` — 300ms |

사이드바 상단 **장비 모델** 드롭다운에서 모델을 선택하면 통신 속도와 파싱 방식이 자동 변경됩니다.

## 2. 앱 사용 절차

1. 런처에서 **SP-2100 / TL-2200** 카드 클릭
2. 사이드바에서 **장비 모델**, **Test Speed**, **Initial Delay**, **Averaging Time**, **그룹당 개수** 설정
   (설정값은 자동 저장되어 다음 실행 시 복원됩니다)
3. 연결 후 **장비에서 측정을 실행**하면 결과가 자동으로 테이블에 추가됨
4. 그룹이 완성되면 우측 **AVG 분포 수염차트**가 자동 갱신
5. 테이블의 **이름** 칸을 클릭해 제품명을 언제든 수정 가능 (기본 이름: `제품 N`)

## 3. 측정 기록 테이블

| 컬럼 | 설명 |
|---|---|
| # | 그룹-내번호 자동 채번 (예: 1-1, 1-2 …) |
| 이름 | 제품명 — 클릭해서 직접 편집 |
| **AVG** | 평균 박리력 (gf) — 굵게 강조, 소수점 2자리 |
| SP | 시작 피크 (gf) |
| KP | 최대 피크 (gf) |
| VAL | 측정값 (gf) |
| RMS | RMS 값 (gf) |

CSV/복사 헤더: `#,Name,AVG,SP,KP,VAL,RMS`

## 4. 측정값 인식 규칙 (중요)

- **SP-2100**: `AVG` / `PEAK` 라벨이 포함된 라인만 측정으로 인정
- **TL-2200**: `TL-22...` 토큰이 포함된 CSV 형식만 인정
- 장비가 측정을 **완료(COMPLETE)** 해야 값이 전송됩니다 — 진행 중에는 기록되지 않음

## 5. 파형 표시

- **TL-2200**: 실제 측정 트리거 완료 시에만 ASCII 파형이 수신되어 표시됩니다. idle 폴링 응답에는 파형이 없습니다.
- **SP-2100**: 장비에서 파형 데이터 수집이 불가하여 파형 그래프는 지원하지 않습니다.

## 6. 문제 해결

| 증상 | 해결 |
|---|---|
| 측정값이 기록 안 됨 | 장비에서 측정을 완료해야 AVG/PEAK 라인이 전송됨 |
| 연결 후 아무 반응 없음 | 장비 모델 선택이 실제 장비와 일치하는지 확인 (보레이트가 다름) |
| 값이 이상하게 파싱됨 | 모델 드롭다운 재확인 — SP-2100과 TL-2200은 응답 형식이 다름 |
