1. 이 장비는 무엇인가요?

PST-3202는 "전기를 공급하는 장비"입니다.

건전지가 1.5V의 전기를 내보내듯, 이 장비는 원하는 전압과 전류를 정밀하게 만들어 시료(샘플)에 공급합니다. 건전지와 다른 점은:

  • 전압을 0V부터 원하는 값까지 자유롭게 설정할 수 있고
  • 전류가 너무 많이 흐르지 않도록 한계를 걸 수 있으며
  • 3개의 독립된 출력(채널)을 동시에 쓸 수 있다는 것입니다.

채널별 사양 (외울 필요 없음 — 앱이 자동으로 막아줍니다)

채널최대 전압최대 전류주 용도
CH132 V2 A샘플 1
CH232 V2 A샘플 2
CH36 V5 A저전압 샘플

꼭 알아야 할 두 가지 개념

용어쉬운 설명
전압 (V, 볼트)전기를 "미는 힘". 수도관의 수압과 같습니다.
전류 (A, 암페어)실제로 "흐르는 전기의 양". 수도관에 흐르는 물의 양과 같습니다.
💡 전류 제한이 왜 필요한가요?
시료에 이상이 생겨(합선 등) 전기가 갑자기 많이 흐르면 시료가 타거나 위험할 수 있습니다. "전류 제한"을 걸어두면 그 이상은 절대 흐르지 않아 시료와 장비를 보호합니다.

2. 장비 연결하기

준비물

  • PST-3202 본체 + 전원 케이블
  • USB↔RS-232C 변환 케이블
  • 시료 연결용 바나나 케이블 (빨강 = +, 검정 = −)

연결 순서

  1. PST-3202 뒷면 RS-232 포트에 케이블을 꽂고 PC USB에 연결
  2. PST-3202 전원 ON
  3. 앱 실행 → 런처에서 PST-3202 카드 클릭
  4. 상단 [연결 안됨] 버튼 클릭 → COM 포트 선택 → 연결
  5. 상단이 [연결됨](초록)으로 바뀌면 준비 완료
⚠ 포트 목록에 아무것도 없으면 USB-Serial 드라이버(CH340/FTDI 등)를 설치하세요.

시료 연결

  • 시료의 (+)를 채널의 빨간 단자에, (−)를 검정 단자에 연결
  • 극성(+/−)을 반대로 연결하지 않도록 주의

2-1. 접지(GND) 단자는 언제 쓰나요?

CH1과 CH2 사이에 있는 접지 단자는 섀시(프레임) 접지입니다. 각 채널의 (+)(−) 출력과는 전기적으로 분리되어 있고, 전원 코드의 접지선(어스)에 내부적으로 연결되어 있습니다.

상황접지 단자 필요 여부
일반적인 저항체·소자 평가 (CH의 +/−만 시료에 연결)❌ 불필요
전기 자극으로 점착력이 변하는 테이프 테스트 (전극 2개에 전류만 흘림)❌ 불필요 — 한 채널의 +/−만으로 회로 완성
CH1↔CH2를 직렬(Series) 트래킹으로 묶어 ±대칭 전원(예: ±16V) 만들 때✅ 필요 — CH1(−)·CH2(+) 접점을 접지에 연결
금속 지그(고정틀)에 시료를 물려 테스트할 때✅ 권장 — 지그를 접지해 감전·정전기 안전 확보
저전압/미세전류 측정이라 노이즈가 걱정될 때✅ 권장 — 접지로 전위 기준점을 잡아 노이즈 저감
💡 핵심 요약: 시료에 단순히 전압/전류를 흘려 넣는 대부분의 평가(테이프 점착력, 저항 등)는 채널 하나의 (+)/(−) 두 선만으로 충분하며 접지 단자는 필요 없습니다. 접지는 직렬 트래킹으로 양/음 전원을 만들 때, 그리고 안전·노이즈 목적으로만 사용합니다.

4. 빠른 시작 (5분 요약)

예: 샘플에 12V, 최대 0.5A로 전기를 공급하고 싶을 때

  1. 연결 (2번 참고)
  2. CH1 카드의 전압 설정에 12 입력 → Enter
  3. 전류 제한에 0.5 입력 → Enter
  4. 하단의 출력 ON 버튼 클릭
  5. LED 디스플레이에 실제 전압·전류가 표시되고, 그래프가 그려지기 시작
  6. 끝나면 출력 OFF → 평가 기록이 자동 저장됨
💡 값 입력 시 걱정하지 마세요: 최대값(32V)을 넘는 값을 입력하면 앱이 자동으로 최대값으로 조정하고 입력칸 아래에 ↩ 최대 32V로 자동 조정됨 안내가 표시됩니다. 잘못된 값으로 장비가 손상될 일이 없습니다.

5. ⚡ 전압 제어 vs 🔋 전류 제어 — 무엇을 고르나요?

모드동작언제 사용?
⚡ 전압 제어 (CV)설정한 전압을 일정하게 유지. 전류는 시료에 따라 자연히 결정됨대부분의 경우 이것 (기본값)
🔋 전류 제어 (CC)설정한 전류를 일정하게 유지. 전압은 자동으로 변함일정 전류가 필요한 특수 시험 (LED, 도금 등)
  • 전류 제어 모드에서는 전압이 채널 최대값으로 걸리고, 전류만 목표값에 고정됩니다.
  • 헷갈리면 ⚡ 전압 제어를 쓰세요.

6. 📌 고정값 모드 vs 🔄 사이클 모드

고정값 모드 (기본)

설정한 전압·전류를 계속 유지합니다. 대부분의 평가에 사용합니다.

사이클 모드

시간에 따라 값을 자동으로 바꿔가며 공급합니다.

예: "5V로 10초 → 10V로 20초 → 0V로 5초"를 3회 반복

  1. 채널 카드 하단의 🔄 사이클 탭 클릭 → 화면 하단에 사이클 편집기가 열림
  2. 전압, 전류, 시간(초)을 입력하고 ➕ 단계 추가
  3. 필요한 만큼 단계를 추가 (표에서 직접 수정·삭제 가능)
  4. 반복 횟수 설정 → 예상 소요 시간이 자동 계산됨
  5. ▶ CH시작 (해당 채널만) 또는 ▶ 전체 시작 (사이클 설정된 모든 채널 동시)
💡 사이클 편집기의 입력 범위도 자동 검증됩니다. 예를 들어 3채널 동기화 중이면 전압 범위가 (0–6V)로 표시되고 초과 입력 시 자동 조정됩니다.

7. 채널 동기화 — 같은 조건으로 여러 샘플 동시 평가

"샘플 2개(또는 3개)에 완전히 같은 조건을 걸고 싶다"면 동기화를 쓰세요.

CH1 ↔ CH2 동기화

  1. CH1과 CH2 카드 사이의 동기화 토글을 ON
  2. 이후 CH1의 전압/전류를 바꾸면 CH2에 자동으로 복사됩니다
  3. 동기화 중에는 점이 흘러내리는 애니메이션이 표시됩니다

CH3까지 동기화 (3채널 동시)

  1. CH1↔CH2 동기화가 ON인 상태에서 CH3 동기화 토글이 나타남
  2. ON 하면 CH3도 CH1과 같은 값으로 묶입니다. 단, CH3 사양에 맞춰 전압 최대 6V, 전류 최대 2A(3채널 통일을 위한 제한)로 제한됩니다
  3. CH1 전압이 6V를 넘는 상태에서 켜면 세 채널 모두 6V로 자동 조정됩니다
  4. CH3 카드의 입력은 잠기고 스펙 표시가 0–6 V / 0–2 A (동기화)로 바뀝니다
⚠ 병렬/직렬 트래킹과 혼동하지 마세요!
사이드바의 병렬/직렬 트래킹은 물리적 배선을 바꿔 출력을 합치는 기능으로, 독립된 샘플 여러 개를 동시 평가하는 용도가 아닙니다. 여러 샘플 동시 평가에는 반드시 독립 모드 + 동기화 토글을 사용하세요.

8. 보호 기능 — OCP와 OVP

기능풀네임하는 일
OCP 보호Over Current Protection (과전류 보호)설정한 전류 제한을 초과하면 출력을 자동 차단
OVP 설정Over Voltage Protection (과전압 보호)출력 전압이 설정한 한계를 넘으면 출력을 자동 차단
  • OCP: 체크박스로 ON/OFF
  • OVP: 버튼 클릭 → 한계 전압 입력 팝업
💡 편리한 설정 위치: 이 보호 기능들은 각 채널 카드뿐만 아니라, 화면 하단의 🔄 사이클 시퀀스 편집기 헤더(CH 선택 탭 왼쪽)에서도 바로 설정할 수 있습니다. 현재 선택(편집) 중인 채널의 OCP/OVP 상태가 실시간으로 동기화되어 나타납니다. 처음 사용하는 시료라면 OCP를 켜두는 것을 적극 권장합니다.

9. 입력값 검증 — 앱이 실수를 막아주는 방식

입력 상황앱의 동작
최대값 초과 (예: CH1에 40V)즉시 최대값으로 자동 수정 + ↩ 최대 32V로 자동 조정됨 표시
3채널 동기화 중 CH1에 6V 초과↩ 3채널 최대 전압(6V)으로 조정됩니다 표시, Enter 시 6V로 적용
음수 입력⚠ 0V 이상 입력 경고 표시
정상 범위안내 없음, 그대로 적용

전류 입력값은 항상 소수점 3자리로 표시됩니다 (예: 2 입력 → 2.000).

💡 숫자 입력칸은 노트북/키보드의 숫자 키로만 입력하도록 설계되어 있습니다 — 화살표 키(↑/↓)로 값이 바뀌지 않아 실수로 값이 변경될 걱정이 없습니다.

10. 실시간 그래프와 평가 기록

  • 출력 ON 하면 그래프가 시작되고 채널별 전압(실선)·전류(점선)가 실시간 표시됩니다
  • 사용하지 않는 채널("사용" 토글 OFF)은 그래프에 나타나지 않습니다
  • 출력 OFF 하면 해당 세션이 평가 기록으로 자동 저장됩니다
  • 저장된 기록은 우측 패널에서 확인·엑셀 내보내기 가능합니다
  • 자동 정지: 설정 시간 경과 후 출력을 자동으로 끄는 기능 (장시간 평가용)

10-1. 평가 목록을 다른 컴퓨터로 옮기기

측정 기록은 이 컴퓨터에 자동 저장되지만, 다른 컴퓨터에서도 이전 기록을 보고 싶다면 Data Table 영역의 두 버튼을 사용하세요.

버튼동작
📤 목록 내보내기현재 평가 기록 전체를 PST3202_records_날짜시간.json 파일로 다운로드
📂 목록 가져오기파일을 선택하면 그 안의 기록을 현재 목록에 추가합니다

사용 순서 (예: 컴퓨터 A → 컴퓨터 B로 이동)

  1. 컴퓨터 A에서 📤 목록 내보내기 클릭 → JSON 파일이 다운로드됨
  2. USB 등으로 이 파일 하나만 컴퓨터 B로 옮김
  3. 컴퓨터 B의 PST-3202 화면에서 📂 목록 가져오기 클릭 → 방금 옮긴 파일 선택
  4. 컴퓨터 B의 기존 기록 뒤에 가져온 기록이 추가됨
💡 같은 기록을 두 번 가져와도 안전합니다. 측정 시각(타임스탬프)이 완전히 같은 기록은 자동으로 건너뛰고 중복 추가하지 않습니다. 가져오기 완료 시 "N개 추가됨, M개는 중복이라 제외됨" 안내가 표시됩니다.

가져온 기록도 일반 기록과 똑같이 취급되므로, 체크박스로 선택해 📥 Raw Data (xlsx)로 엑셀 내보내기하는 것도 그대로 가능합니다.

10-2. 📥 Raw Data (xlsx) — 엑셀로 내보내면 어떤 모습인가요?

Data Table에서 기록을 체크박스로 선택하고 📥 Raw Data (xlsx) 버튼을 누르면 엑셀 파일 하나에 시트가 2개 만들어집니다.

시트 이름내용
채널별선택한 기록의 시간별 측정값(전압/전류) 원본 데이터 표
Graph각 기록의 전압·전류 변화를 보여주는 그래프 이미지

두 시트 모두 같은 방식으로 배치됩니다 — 기록 하나당 위에는 제목, 아래에는 표(또는 그래프)가 놓이고, 기록을 여러 개 선택했다면 오른쪽으로 차례차례 이어붙습니다. 그래프끼리 겹치지 않도록 충분한 간격이 자동으로 확보됩니다.

Graph 시트의 그래프 상단에는 어떤 색이 전압이고 어떤 색이 전류인지 바로 알아볼 수 있도록 범례가 함께 표시됩니다 (실선 = 전압, 점선 = 전류):

  • 채널이 여러 개면 CH1 V/CH1 I, CH2 V/CH2 I처럼 채널별로 나뉘어 표시됩니다
  • 직렬(Series) 트래킹으로 측정한 기록은 CH1·CH2가 합쳐진 값 하나로만 표시됩니다 (직렬 합산 V, 직렬 평균 I) — 전압은 두 채널이 더해지고(V1+V2), 전류는 두 채널이 전기적으로 공유되므로 CH1·CH2 측정값의 평균으로 기록됩니다 (7번 채널 동기화 및 병렬/직렬 트래킹 설명 참고)

11. 자주 묻는 질문 (FAQ)

Q. 출력을 켰는데 전류가 0으로 나와요.
A. 정상일 수 있습니다. 전류는 시료가 연결되어 실제로 전기가 흘러야 표시됩니다. 시료 연결과 극성(+/−)을 확인하세요.
Q. 전압을 입력했는데 적용이 안 돼요.
A. 입력 후 Enter를 눌러야 적용됩니다. 입력칸 아래 경고 메시지도 확인하세요.
Q. CH2 설정이 안 바뀌어요.
A. CH1↔CH2 동기화가 ON이면 CH2는 CH1을 따라갑니다. 개별 설정하려면 동기화를 끄세요. 병렬/직렬 트래킹 모드에서도 일부 채널이 잠깁니다.
Q. 설정한 전류 제한보다 전류가 안 올라가요.
A. 그것이 정상입니다 — "전류 제한"은 그 이상 흐르지 못하게 막는 안전장치입니다. 더 필요하면 제한값을 올리세요 (최대 2A/5A).
Q. 출력 OFF 상태인데 LED에 값이 안 나와요.
A. 출력이 꺼져 있으면 측정 폴링도 멈춥니다 (불필요한 통신 방지). 정상 동작입니다.
Q. 3채널 동기화를 켰더니 전압이 6V로 떨어졌어요.
A. CH3의 물리적 최대 전압이 6V라서, 3채널을 같은 값으로 묶으려면 6V 이하만 가능합니다. 6V 초과가 필요하면 CH3 동기화를 끄고 CH1↔CH2만 동기화하세요 (32V까지 가능).
Q. CH1·CH2 사이의 접지 단자는 언제 연결하나요?
A. 대부분의 경우 연결할 필요가 없습니다. 시료에 전압/전류를 흘리는 일반적인 평가는 채널 하나의 (+)/(−)만으로 충분합니다. 접지는 직렬 트래킹으로 ±전원을 만들거나, 금속 지그 안전접지·노이즈 저감이 필요할 때만 사용하세요 (2-1 참고).
Q. 전기 자극으로 점착력이 변하는 테이프를 테스트할 때도 접지가 필요한가요?
A. 아니요. 테이프의 전극 2개를 한 채널의 (+)/(−)에 바로 연결하면 회로가 완성되므로 접지 단자는 필요 없습니다. 다만 금속 지그를 쓰거나 신호가 미세해 노이즈가 걱정되면 안전·안정성 목적으로 접지를 추가로 연결해도 됩니다.
Q. 엑셀로 내보낸 그래프에서 전압/전류 선 색이 헷갈려요.
A. Graph 시트의 각 차트 상단에 범례가 표시됩니다 — 실선은 전압, 점선은 전류이며 채널별로 색이 다릅니다 (10-2 참고). 화면의 실시간 그래프와 동일한 색상입니다.
