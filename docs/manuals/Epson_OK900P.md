# Epson PRIFIA OK900P — 라벨 편집·인쇄

통합 프로그램의 OK900P 화면은 테이프 규격에 맞춰 편집 요소를 자동 비례 조정하고,
텍스트·바코드·QR·이미지를 360 DPI 미리보기와 Windows 인쇄 경로에 반영합니다.

주요 기능은 1D/2D 바코드, 시리얼 카운터(시작값~종료값), 드래그 다중 선택, 일괄 정렬·회전·삭제,
Delete 키 삭제, 되돌리기, 프린터 검색 및 XLSX 배치 인쇄입니다. 배경색은 실제 1-bit 흑백
인쇄 결과에 반영되지 않으므로 편집 대상에서 제외되어 있습니다.

레이아웃과 편집기 변경 시에는 [통합 레이아웃 계약](../INTEGRATED_LAYOUT_CONTRACT.md)을
따르며, EXE는 `dist/3M_Instrument_Logger.exe` 하나만 배포합니다.
