# Hioki 3540 (mΩ HiTESTER) — 사용 매뉴얼

저항을 mΩ 단위까지 정밀 측정하는 저항계입니다. ✅ 실기 동작 확인 완료.

## 1. 통신 사양

| 항목 | 값 |
|---|---|
| Baud Rate | 9600 (장비 고정, 변경 불가) |
| Data / Parity / Stop | 8 / None / 1 |
| 종단문자 | CR (`\r`) |
| 폴링 | `RMES\r` — 400ms 간격 자동 |

## 2. 계측기 측 준비

1. 본체에서 **RS-232C 인터페이스**가 활성화되어 있는지 확인
2. 통신 속도 9600 bps, 터미네이터 CR 설정
3. USB↔RS-232C 케이블로 PC와 연결

## 3. 앱 사용 절차

1. 런처에서 **Hioki 3540** 카드 클릭
2. 상단 **[연결 안됨]** 버튼 → COM 포트 선택 → 연결
3. 연결되면 400ms마다 저항값이 자동 갱신됨
4. 사이드바에서 **테스트 방법**(MSL-2 등) 선택 → 그룹 크기·컬럼 자동 설정
5. **기록 시작** 버튼 → 측정값이 그리드에 자동으로 채워짐
6. 데이터 완성 후 **복사**(엑셀 붙여넣기용) 또는 **CSV 저장**

## 4. 사이드바 설정

| 항목 | 설명 |
|---|---|
| 샘플링 속도 | FAST / SLOW (`SMP 1` / `SMP 0`) |
| 측정 레인지 | Auto (`AUTO 1`) 또는 수동 레인지 (`RNG <code>`) |
| 테스트 방법 | 규격별 그룹 크기 자동 설정 |

## 5. 표시값 해석

| 표시 | 의미 |
|---|---|
| 숫자 (Ω) | 정상 측정값 — 유효숫자 5자리 |
| Over Flow | 측정 범위 초과 (`OF` 응답) |
| Current Error | 측정 전류 이상 (`----` 응답) |
| Cmd Error | 명령 오류 (`ERR` 응답) |

## 6. 문제 해결

- **값이 안 들어옴**: 케이블 확인 → 본체 RS-232C 활성화 여부 확인 → 재연결
- **Over Flow 지속**: 프로브 접촉 불량 또는 시료 저항이 레인지 초과 — 레인지를 Auto로 설정
