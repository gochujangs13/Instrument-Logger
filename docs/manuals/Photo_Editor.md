# Photo Editor (사진 편집 · 엑셀 내보내기) — 사용 매뉴얼

시료 사진을 수집·크롭하여 엑셀(.xlsx)에 격자로 배치해 내보내는 소프트웨어 도구입니다. 계측기 연결이 필요 없습니다.

## 1. 사진 수집 방법 3가지

| 방법 | 절차 |
|---|---|
| 파일 업로드 | 좌측 **📁 파일 선택** 버튼 또는 드래그앤드롭 |
| USB 현미경 | USB 현미경 연결 → 카메라 목록에서 자동 선택 → 📷 촬영 |
| 스마트폰 카메라 | 아래 "폰 연동" 참고 |

## 2. Step 1 — 편집

1. 좌측 파일 목록에서 사진 클릭 → 메인 뷰에 표시
2. **크롭 영역**: 드래그로 새로 그리기 / 이동 / 4모서리 핸들로 크기 조절
3. **회전**: 슬라이더 −15°~+15° (±0.1° 스텝 버튼)
4. **줌/팬**: 휠 줌, 우클릭(또는 중클릭) 드래그로 이동
5. **크롭 자동 맞춤**: 선택한 사진의 크롭 영역을 템플릿 삼아 나머지 사진들의 크롭 위치를 자동 추정
6. **출력 크기(인치)** 와 **한 열 개수** 설정 (자동 저장됨)
7. **다음 단계 ▶** 클릭

## 3. Step 2 — 미리보기 / 내보내기

- 크롭된 사진들이 그룹 격자로 배치되어 미리보기됨
- 썸네일 클릭 → 보정 모달(회전 미세 조정)
- **엑셀로 내보내기**: `.xlsx` 생성 — 그룹당 사진들이 하나의 그룹 개체로 묶여
  Excel에서 통 선택/이동 가능 (우클릭 → 그룹 해제로 개별 선택)
- **ZIP 저장**: 모든 사진을 `photos.zip` 한 파일로 다운로드

⚠ 엑셀 내보내기는 CDN(ExcelJS/JSZip)을 사용하므로 인터넷 연결이 필요합니다.

## 4. USB 현미경 사용

1. USB 현미경을 PC에 연결
2. 카메라 목록에서 자동으로 현미경이 우선 선택됨 (내장 웹캠 자동 제외)
3. 줌 슬라이더로 배율 조정, 크롭 영역 설정
4. **📷 촬영** — 파일명이 `그룹-위치` 형식(예: `1-1.jpg`~`1-6.jpg`)으로 자동 생성

## 5. 스마트폰 카메라 연동

1. `시작.bat`으로 앱 실행 (`python server.py` 필수)
2. 사이드바 **▶ 폰 연동 시작** 클릭
3. **USB**: ADB 자동 연결 → 폰 브라우저에서 `http://localhost:8000/phone.html`
4. **WiFi**: 같은 WiFi 연결 → 폰에서 `http://[PC IP]:8000/phone.html`
5. 폰에서 **● 촬영 → 업로드** → 사이드바에 사진 자동 추가

💡 **덮어쓰기 촬영**: 파일 목록에서 체크박스 선택 후 촬영하면 해당 파일이 교체됩니다 (재촬영용).

## 6. 문제 해결

| 증상 | 해결 |
|---|---|
| 엑셀 내보내기 실패 | 인터넷 연결 확인 (CDN 필요) |
| 현미경 대신 내장캠이 잡힘 | 카메라 드롭다운에서 직접 선택 |
| 폰 라이브뷰 6초+ 지연 | 정상 — 첫 프레임 전송까지 5~7초 소요 |
| 자동 맞춤이 느림 | 사진 수·해상도에 비례 — 잠시 대기 |
