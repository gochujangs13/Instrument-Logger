## 2. 조작 패널 키 기능 (Key Functions)

### 전면 패널 키

| 키 | 기능 |
|---|---|
| **① Up** | 키를 누르는 동안 스핀들 상승. 측정 후 접촉자를 워크피스에서 후퇴시킬 때 사용 |
| **② Down** | 키를 누르는 동안 스핀들 하강. 접촉자를 워크피스에 접촉시켜 측정할 때 사용 |
| **③ Rapid Up** | 키를 누르는 동안 스핀들 고속 상승. 위치 간 빠른 이동 |
| **④ Rapid Down** | 키를 누르는 동안 스핀들 고속 하강. 위치 간 빠른 이동 |
| **⑤ ZERO** | 현재 접촉자 위치를 원점으로 설정하고 모든 디스플레이 값을 0으로. 에러 클리어 기능도 겸함 |
| **⑥ PRESET** | 현재 접촉자 위치를 기준으로 입력된 높이값으로 원점 설정. 표준 워크피스나 게이지 블록과 함께 사용 |
| **⑦ MODE** | MAX/MIN 측정 등 다양한 측정 모드 선택 및 설정 |
| **⑧ LIMIT** | GO/NG 공차 판정 측정을 위한 크기 한계값 입력 |
| **⑨ TEACH** | 위치 메모리 설정 |
| **⑩ PM1~PM3** | 저장된 임의 위치로 스핀들을 한 번의 키 조작으로 이동 |

## 4. RS-232C 통신 사양

### 4.1 통신 설정

| 파라미터 | 설정값 |
|---|---|
| **통신 방식** | Half-duplex, Non-procedural |
| **보레이트** | 4800 / **9600** / 19200 bps (파라미터로 선택) |
| **데이터 비트** | 7 또는 8 (ASCII, 대문자) |
| **패리티** | None / Even / Odd (파라미터로 선택) |
| **스톱 비트** | 2 |
| **인터페이스** | EIA RS-232C 호환 |
| **케이블** | 크로스(Null-modem) 케이블 필요 |

### 4.2 커맨드 레퍼런스

| 커맨드 | 응답 형식 | 설명 |
|---|---|---|
| `GA**<CR><LF>` | `G#**,±01234.567<CR><LF>` | 현재 디스플레이 값 출력. `**` = 게이지 채널(01~99), `00` = 전체 채널 |
| `CS<CR><LF>` | `CH<CR><LF>` | 에러 상태 해제 |
| `VS,+<CR><LF>` | `CH<CR><LF>` | 스핀들 UP (상승) |
| `VS,-<CR><LF>` | `CH<CR><LF>` | 스핀들 DOWN (하강) |
| `VS,$<CR><LF>` | `CH<CR><LF>` | 속도 지정. `$` 값: 0=정지, 1=2mm/s, 2=4mm/s, 3=8mm/s |
| `VT,<CR><LF>` | `CH,#<CR><LF>` | 스핀들 상태 확인. `#` 값: 0=정상, 1=상사점(Upper dead point), 2=WORK ON |

### 4.3 커맨드 사용 주의사항

1. **채널 `00`**: 데이터 요청(`GA`)용으로만 사용 가능. 제어 명령에는 사용 불가.
2. **응답 대기**: 커맨드 전송 후 반드시 장비의 응답(`CH` 등)을 대기한 후 다음 커맨드를 전송해야 함.
3. **키 조작 중**: RS-232C 출력은 물리 키 조작 중 홀드됨.
4. **응답 형식**: `GA` 커맨드의 응답에서 `G#**` 부분은 `G` + 에러상태(`#`) + 채널번호(`**`). 정상 시 `#` = 공백.

### 4.4 GA 응답 파싱 형식

```
G#CC,±DDDDD.DDD<CR><LF>
│││  │└─ 측정값 (부호 포함 숫자)
│││  └── 쉼표 구분자
││└── CC = 채널 번호 (01~99)
│└── # = 에러 코드 (공백=정상)
└── G = 헤더
```

### 4.5 RS-232C 커넥터

- **커넥터 타입**: 표준 RS-232C (D-Sub)
- **적용 플러그**: No. 02ADB440 (단자 커버 포함)
- **적용 리셉터클**: 10236-52A2 (3M) 또는 동등품

## 6. 파라미터 설정 가이드 (P.No. 00~40)

### 6.1 파라미터 모드 진입

파라미터 모드는 디스플레이 유닛의 인터페이스를 통해 접근합니다.

### 6.2 주요 파라미터 카테고리

| 카테고리 | 포함 설정 | 관련 P.No. |
|---|---|---|
| **잠금/해제** | 파라미터 수정 모드 잠금 제어 | **P.No. 00** |
| **통신 설정** | 보레이트, 데이터 비트, 패리티, 출력 모드(RS-232C/Digimatic) | P.No. 범위 내 |
| **측정 동작** | 스핀들 속도, 스무딩, 측정 모드(Normal/Max/Min/Diff) | P.No. 범위 내 |
| **인터페이스/I/O** | 풋스위치 설정, 공차 판정(3단/5단) | P.No. 범위 내 |
| **시스템/디스플레이** | 단위(mm/inch), 프리셋 초기화 | P.No. 범위 내 |

### 6.3 RS-232C 통신 활성화 절차

1. **P.No. 00**으로 이동하여 파라미터 수정 모드 **잠금 해제**
2. RS-232C 관련 파라미터로 이동
3. 출력 모드를 **RS-232C**로 설정
4. 보레이트를 **9600** (또는 원하는 값)으로 설정
5. 데이터 비트, 패리티, 스톱 비트를 PC 측 설정과 일치시킴
6. 설정 완료 후 P.No. 00으로 복귀하여 파라미터 **잠금**

> ⚠️ **중요**: 파라미터 변경 전 반드시 현재 설정값을 기록해 두십시오.
> 잘못된 파라미터 변경은 측정력이나 측정 정밀도에 영향을 줄 수 있습니다.

## 7. 에러 코드 및 트러블슈팅

### 7.1 에러 클리어 방법
1. 전면 패널의 **ZERO** 키를 눌러 에러 클리어
2. RS-232C로 `CS<CR><LF>` 커맨드 전송
3. 외부 제어 커넥터의 **HOLD** 신호 리딩 엣지로 클리어

### 7.2 일반 트러블슈팅
1. **물리적 연결 확인**: 모든 케이블(전원, 데이터) 확실히 체결 확인
2. **전원 리셋**: 전원 OFF → 플러그 분리 → 10초 대기 → 재시작
3. **RS-232C 통신 실패 시**: 
   - 보레이트, 패리티, 데이터 비트 설정 확인 (장비 ↔ PC 일치 여부)
   - 크로스(Null-modem) 케이블 사용 여부 확인
   - P.No. 파라미터에서 RS-232C 출력 모드가 활성화되어 있는지 확인

## 12. RS-232C 프로그래밍 Quick Reference

### Python 시리얼 설정 (권장)

```python
import serial

ser = serial.Serial(
    port='COMx',           # 실제 포트로 변경
    baudrate=9600,          # 장비 파라미터와 일치
    bytesize=serial.SEVENBITS,   # 7비트 데이터
    parity=serial.PARITY_EVEN,   # Even 패리티
    stopbits=serial.STOPBITS_TWO, # 스톱 비트 2
    timeout=1,
    dsrdtr=True,            # DSR/DTR 흐름 제어
    rtscts=True             # RTS/CTS 흐름 제어
)
```

### 데이터 요청 예시

```python
# 채널 01 데이터 요청
ser.write(b'GA01\r\n')

# 응답 읽기 (예: "G 01,+00012.345\r\n")
response = ser.readline().decode('ascii')

# 파싱
# response[0]   = 'G' (헤더)
# response[1]   = ' ' (에러상태, 공백=정상)
# response[2:4] = '01' (채널)
# response[4]   = ',' (구분자)
# response[5:]  = '+00012.345\r\n' (측정값)
value = float(response[5:].strip())
```

### 스핀들 제어 예시

```python
# 스핀들 상승
ser.write(b'VS,+\r\n')     # 응답: CH\r\n

# 스핀들 하강
ser.write(b'VS,-\r\n')     # 응답: CH\r\n

# 스핀들 정지
ser.write(b'VS,0\r\n')     # 응답: CH\r\n

# 속도 변경 (2=4mm/s)
ser.write(b'VS,2\r\n')     # 응답: CH\r\n

# 에러 클리어
ser.write(b'CS\r\n')       # 응답: CH\r\n

# 스핀들 상태 확인
ser.write(b'VT,\r\n')      # 응답: CH,0\r\n (0=정상)
```
