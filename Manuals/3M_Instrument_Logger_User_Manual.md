# 3M Instrument Logger - 설정 및 사용 매뉴얼

본 매뉴얼은 3M 정밀 측정 시스템(저항 및 두께 측정)의 통합 로깅 소프트웨어인 **3M Instrument Logger**의 장비 설정과 데이터 수집 방법을 설명합니다.

---

## 1. 장비 연결 및 통신 설정

프로그램 좌측 사이드바의 **[통신 설정]** 영역에서 장비와 PC를 연결합니다.

1. **장비 선택**: 드롭다운 메뉴에서 사용할 계측기를 선택합니다.
   * `Hioki 3540` (초정밀 저항계)
   * `Keithley 2700` (멀티미터/스위치 시스템)
   * `Mitutoyo VL-50` (초정밀 두께 측정기)
   > **주의**: 이미 연결된 상태에서 장비를 변경하려면 먼저 **[연결 해제]** 버튼을 눌러야 합니다.
2. **포트 설정**: 장비가 연결된 USB/RS-232C 포트(예: `COM3`)를 선택합니다. 포트가 보이지 않으면 **[포트 새로고침]** 버튼을 클릭하세요.
3. **연결**: **[디바이스 연결]** 파란색 버튼을 클릭하여 장비와 통신을 시작합니다. 상태가 `● ONLINE`으로 변경되면 정상입니다.

---

## 2. 저항 계측 모드 (Hioki 3540 / Keithley 2700)

저항 계측기를 선택하면 전용 설정 메뉴와 분할 데이터 시트가 화면에 나타납니다.

### 2.1. 장비 상세 설정
* **샘플링 속도**: 데이터 수집 속도를 설정합니다. (FAST / MED / SLOW) *※ Hioki는 FAST/SLOW만 지원*
* **측정 레인지**: 측정 범위를 선택합니다. 기본값은 `Auto`이며, 30mΩ ~ 30kΩ까지 수동 지정이 가능합니다. *(Keithley는 제외)*
* **측정 방식 (Keithley 전용)**: `2-Wire` 또는 `4-Wire` 방식을 선택합니다. (Hioki 선택 시 4-Wire로 자동 고정)
* **자동 기록 대기 (초)**: 탐촉자가 제품에 닿은 뒤, 값이 안정화될 때까지 기다렸다가 자동으로 기록하는 딜레이 타임(기본 2.0초)을 설정합니다.
* **출력 분할 화면**: 동시에 여러 그룹을 측정할 때 화면을 1~3분할하여 독립적으로 데이터를 관리할 수 있습니다.

### 2.2. 테스트 방법 관리 (칸 분할)
측정할 제품의 형태에 맞춰 표(Grid)의 열(Column) 개수와 헤더를 직접 커스텀할 수 있습니다.
* **[테스트 방법 관리]** 버튼을 눌러 새 템플릿(예: ETM-7, ETM-18 등)을 추가할 수 있습니다.
* 각 분할 화면 상단의 **[Test 방법]** 드롭다운에서 만들어둔 템플릿을 선택하여 표의 레이아웃을 즉시 변경합니다.

---

## 3. 두께 측정 모드 (Mitutoyo VL-50)

장비 선택 메뉴에서 `Mitutoyo VL-50`을 선택하면 저항 관련 복잡한 설정창이 사라지고, 두께 전용 데이터 시트(Left, Right, Average) 화면으로 자동 전환됩니다.

### 3.1. 수동 데이터 캡처
* **캡처 방식**: 자동 폴링 방식이 아닌 **수동 캡처 방식**으로 동작합니다.
* **사용법**: VL-50 계측기로 두께를 측정한 뒤, 키보드의 **`Enter`** 키를 누르거나 화면의 파란색 **`CAPTURE DATA (Enter)`** 버튼을 클릭하세요.
* **동작**: 측정된 값(숫자만)이 현재 선택된 하얀색 표 칸에 즉시 기입되며, 커서가 자동으로 다음 칸(Left -> Right -> 다음 줄 Left)으로 이동합니다.
* **평균 자동 계산**: Left와 Right 칸에 모두 데이터가 입력되면 우측에 자동으로 두 값의 평균(Average)이 계산되어 표시됩니다.

---

## 4. 데이터 저장 및 관리 (공통 기능)

* **클립보드 복사 (Copy)**: 
   * 데이터 시트 상단(또는 우측 상단)의 초록색 **[COPY]** 버튼을 클릭합니다.
   * 표에 입력된 내용이 텍스트(엑셀 호환 탭 분리 형식)로 복사됩니다. 단위(mm 등)가 제외된 순수 숫자만 복사되어 엑셀 수식 작업에 바로 활용할 수 있습니다.
* **CSV 엑셀 파일 저장 (Export)**:
   * 화면 최하단의 **[통합 CSV 데이터 보내기]** 또는 VL-50 화면 하단의 **[Export CSV]** 버튼을 누릅니다.
   * 저장할 파일 이름과 경로를 지정하여 데이터 시트 내용을 `.csv` 파일로 영구 보관할 수 있습니다.
* **전체 삭제 (Clear)**: 화면 하단의 **[Clear All Data]** 버튼을 눌러 현재 화면의 표 내용을 모두 초기화할 수 있습니다.

---

## 5. UI 테마 설정
* 프로그램 우측 상단의 **[테마 설정]** 드롭다운을 통해 `Dark`(다크 모드)와 `Light`(라이트 모드)를 자유롭게 전환할 수 있습니다. 눈의 피로도와 작업 환경의 조명에 맞춰 사용하세요.
