# Keithley DAQ6510 Data Acquisition System 완전 매뉴얼 (읽기 전용)

본 문서는 Keithley DAQ6510 데이터 수집 시스템의 공식 기술 레퍼런스를 바탕으로 작성된 프로그래밍 및 운영 가이드입니다. **이 문서는 프로그램 제작 및 유지보수의 기준 문서로 수정이 금지됩니다.**

---

## 1. 장비 개요 및 통신 설정

Keithley DAQ6510은 6½-digit 멀티미터 기능을 갖춘 데이터 수집 및 로깅 시스템입니다.

### 1.1 통신 인터페이스
*   **USB (기본)**: 후면의 USB Type-B 포트를 사용하여 PC와 연결 (VISA 주소 형식: `USB0::0x05E6::0x6510::[SERIAL]::INSTR`)
*   **LAN (LXI)**: 이더넷 연결 지원. 웹 인터페이스를 통한 제어 가능.
*   **GPIB / RS-232**: 옵션 카드를 통해 지원.

### 1.2 통신 파라미터 (RS-232 기준)
*   **Baud Rate**: 9600 (기본값, 변경 가능)
*   **Data Bits**: 8
*   **Stop Bits**: 1
*   **Parity**: None
*   **Flow Control**: None
*   **Termination**: CR (\r) 또는 LF (\n)

---

## 2. 주요 SCPI 커맨드 레퍼런스

### 2.1 시스템 제어
*   `*RST`: 장비를 공장 출하 상태로 리셋.
*   `*IDN?`: 장비 식별 정보 확인 (제조사, 모델명, 시리얼, 펌웨어).
*   `SYST:ERR?`: 에러 큐(Error Queue) 확인.

### 2.2 측정 설정 (저항 측정 기준)
*   `FUNC "RES", (@ch_list)`: 지정한 채널을 2-Wire 저항 측정 모드로 설정.
*   `FUNC "FRES", (@ch_list)`: 지정한 채널을 4-Wire 저항 측정 모드로 설정.
*   `FRES:RANG [value], (@ch_list)`: 측정 레인지 설정 (예: 100, 1000, 10000). `Auto` 대신 고정 레인지를 사용하면 측정 속도가 빨라짐.
*   `FRES:NPLC [value], (@ch_list)`: 측정 적분 시간(NPLC) 설정 (0.0005 ~ 15). 낮은 값일수록 빠르고, 높은 값일수록 정밀함.
*   `FRES:OCOM [ON|OFF], (@ch_list)`: 오프셋 보정(Offset Compensation) 설정. 낮은 저항 측정 시 열기전력(EMF) 영향을 제거하기 위해 필수적으로 **ON** 권장.

### 2.3 스캐닝 및 데이터 수집
*   `ROUT:SCAN:LIST (@ch_list)`: 스캔할 채널 목록 설정.
*   `ROUT:SCAN:COUN:SCAN [number]`: 전체 스캔 반복 횟수 설정.
*   `ROUT:SCAN:INT [seconds]`: 스캔 간의 간격 시간 설정.
*   `INIT`: 스캔 시작.
*   `READ?`: 즉시 측정값을 읽어옴.
*   `TRAC:DATA? [start], [count], "defbuffer1"`: 내부 버퍼에 저장된 데이터 읽기.

## 3. 프로그래밍 가이드 및 코딩 검토 (Deep Analysis)

### 3.1 효율적인 데이터 수집 방식
현재 구현된 방식(채널마다 `ROUT:CLOS` 후 `READ?`)은 하드웨어 명령을 매번 주고받으므로 속도가 느리고 오버헤드가 큽니다. 대량의 데이터를 빠르게 수집하려면 **장비 내장 스캔 기능**을 활용하는 것이 유리합니다.

**권장되는 SCPI 시퀀스:**
1. `*RST`
2. `FUNC "FRES", (@101:110)` (채널 설정)
3. `FRES:OCOM ON, (@101:110)` (오프셋 보정 활성화)
4. `ROUT:SCAN:LIST (@101:110)` (스캔 목록 생성)
5. `INIT` (측정 시작)
6. `TRAC:DATA?` (완료 후 버퍼에서 한꺼번에 읽기)

### 3.2 7700 시리즈 스위치 카드 유의사항
*   DAQ6510은 내부 슬롯에 7700, 7701 등 스위치 모듈을 장착하여 사용합니다.
*   `(@101)` 형식의 채널 번호에서 앞의 `1`은 슬롯 번호를 의미합니다. (슬롯 1의 1번 채널)
*   **4-Wire(FRES) 측정 시**: 인접한 두 채널이 페어(Pair)로 동작합니다 (예: 101번을 FRES로 설정하면 111번이 자동으로 쌍으로 사용됨).

## 4. 유지보수 가이드 (수정 금지 항목)

1.  **타임아웃 설정**: LAN/USB 통신 시 VISA Timeout은 최소 5000ms 이상으로 설정해야 합니다. (스캔 시에는 더 길게 필요)
2.  **데이터 파싱**: `READ?`의 결과값은 보통 지수 표기법(`1.2345E+01`)으로 반환되므로 `float()` 변환이 필요합니다.
3.  **안전 종료**: 프로그램 종료 시 `ROUT:OPEN:ALL` 명령을 전달하여 릴레이의 부하를 해제하는 것이 장비 수명 연장에 도움을 줍니다.
