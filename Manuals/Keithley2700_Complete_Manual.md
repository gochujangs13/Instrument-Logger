# Keithley 2700 Multimeter/Switch System 완전 매뉴얼

이 문서는 Keithley 2700 멀티미터의 공식 사용자 매뉴얼 및 통신 사양을 기반으로 작성된 통합 레퍼런스입니다. RS-232C 인터페이스를 통한 원격 제어 및 정밀 저항 측정에 필요한 핵심 정보를 포함합니다.

## 1. 시스템 개요
*   **모델**: Keithley 2700 (Multimeter / Data Acquisition / Switch System)
*   **측정 항목**: DCV, ACV, DCI, ACI, 저항(2-wire/4-wire), 온도, 주파수 등
*   **채널 확장**: 전면 패널 외에 후면 슬롯을 통해 스위칭 모듈(예: 7700) 지원 가능

## 2. RS-232C 통신 사양
Keithley 2700은 표준 RS-232C 인터페이스를 통해 PC와 통신합니다.

### 2.1 케이블 사양
*   **유형**: 9-핀 DB-9 **Straight-through** 케이블 (Cross/Null Modem 케이블 사용 금지)
*   **커넥터**: 후면 패널의 RS-232 포트

### 2.2 인터페이스 설정 (Front Panel MENU)
1.  `SHIFT` + `RS-232` (또는 `MENU` -> `I/O` -> `RS-232`)
2.  **BAUD**: 300, 600, 1200, 2400, 4800, 9600(기본), 19.2k
3.  **BITS**: 7 또는 8(기본)
4.  **PARITY**: NONE(기본), ODD, EVEN
5.  **FLOW**: NONE(기본), XON/XOFF

## 3. SCPI 명령어 레퍼런스 (저항 측정 중심)
Keithley 2700은 표준 SCPI 명령어를 따릅니다.

### 3.1 기본 시스템 명령
| 명령어 | 기능 |
| :--- | :--- |
| `*RST` | 장치 초기화 (기본 상태로 복구) |
| `*IDN?` | 장치 식별 정보 요청 (제조사, 모델명, 시리얼 등) |
| `SYST:PRES` | 시스템 프리셋 설정 |
| `*CLS` | 에러 큐 및 상태 레지스터 클리어 |

### 3.2 측정 기능 설정
| 명령어 | 기능 |
| :--- | :--- |
| `:FUNC 'RES'` | 2-와이어 저항 측정 모드 선택 |
| `:FUNC 'FRES'` | 4-와이어(정밀) 저항 측정 모드 선택 |
| `:RES:RANG <n>` | 2-와이어 저항 레인지 설정 (예: 1000) |
| `:FRES:RANG:AUTO ON` | 4-와이어 저항 자동 레인지 활성화 |
| `:FRES:NPLC <n>` | 적분 시간(속도) 설정 (0.01 ~ 10, 기본 1.0/FAST는 0.1 이하) |

### 3.3 데이터 읽기 명령
| 명령어 | 기능 |
| :--- | :--- |
| `:READ?` | 측정을 트리거하고 데이터를 즉시 반환 |
| `:MEAS:FRES?` | 4-와이어 저항 모드로 설정 후 측정값 반환 (가장 간편한 방법) |
| `:FETC?` | 가장 최근에 측정된 값을 버퍼에서 가져옴 |

## 4. 고급 저항 측정 설정
### 4.1 Offset-Compensated Ohms (OCOMP)
열기전력(Thermal EMF)에 의한 오차를 제거하기 위한 기능입니다 (100Ω, 1kΩ, 10kΩ 레인지에서 권장).
*   활성화: `:FRES:OCOM ON`
*   비활성화: `:FRES:OCOM OFF`

### 4.2 스위칭 모듈 사용 시 (예: 7700 모듈)
*   채널 닫기: `:ROUT:CLOS (@101)` (1번 슬롯 1번 채널)
*   채널 열기: `:ROUT:OPEN ALL`

## 5. 에러 및 문제 해결
*   **IDN 응답 없음**: 보드레이트 확인 및 Straight 케이블 여부 확인.
*   **"ERR" 응답**: 명령어 오타 또는 현재 모드에서 지원하지 않는 파라미터 사용 시 발생. `SYST:ERR?` 명령어로 구체적인 에러 내용 확인 가능.
*   **9.9E37**: Over Flow (측정 범위를 초과하거나 리드선이 개방된 상태).
