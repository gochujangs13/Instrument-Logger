## 1. 조작 패널 키 기능

| 키 | 기능 |
|---|---|
| **Up / Down** | 스핀들 상승 / 하강 |
| **Rapid Up/Down** | 스핀들 고속 이동 |
| **ZERO** | 원점 설정 및 에러 클리어 |
| **PRESET** | 높이값 프리셋 설정 |

---

## 2. RS-232C 통신 사양

| 파라미터 | 설정값 |
|---|---|
| **보레이트** | 4800 / **9600** / 19200 bps |
| **데이터 비트** | 7 또는 8 (ASCII) |
| **패리티** | None / Even / Odd |
| **스톱 비트** | 2 |
| **케이블** | 크로스(Null-modem) 케이블 |

### 주요 커맨드
- `GA00\r\n`: 현재 디스플레이 값 요청
- `VS,+\r\n`: 스핀들 상승
- `VS,-\r\n`: 스핀들 하강
- `CS\r\n`: 에러 해제
- `VT,\r\n`: 스핀들 상태 확인

---

## 3. 에러 코드 및 트러블슈팅
- 에러 발생 시 디스플레이에 에러 코드 표시
- `ZERO` 키 또는 RS-232C `CS` 커맨드로 해제
- 통신 실패 시 보레이트 및 패리티 설정 재확인 (PC와 장비 일치 필수)
