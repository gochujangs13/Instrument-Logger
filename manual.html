3M Instrument Logger
계측기 통합 로거 — 전체 사용설명서 · Ver 2026-06

앱 개요

3M Instrument Logger는 여러 계측기를 웹 브라우저에서 직접 연결해 측정값을 표시·기록·CSV 내보내기 하는 통합 웹 앱입니다. Web Serial API를 사용하므로 Chrome / Edge 브라우저가 필요하며, 인터넷 연결 없이 로컬에서만 동작합니다.

항목내용
지원 브라우저Chrome 89+ / Edge 89+ (Web Serial 지원 필수)
운영체제Windows 10 / 11 (macOS 미지원)
Python3.10 이상 (Photo Editor 폰 연동 기능 사용 시)
케이블계측기별 RS-232C ↔ USB 변환 케이블
💡 Web Serial API는 보안 컨텍스트(HTTPS 또는 localhost)에서만 동작합니다. 반드시 시작.bat 또는 python server.py로 실행해야 합니다.

시작하기

방법 1 — 시작.bat (권장)

  1. 폴더 내 시작.bat를 더블클릭합니다.
  2. 기존 서버가 종료되고 새 서버가 자동 실행됩니다.
  3. ADB가 설치되어 있으면 폰 연동 터널도 자동 설정됩니다.
  4. 브라우저가 http://localhost:8000/index.html로 자동 열립니다.

방법 2 — 수동 실행

# 터미널에서 실행
cd "C:\경로\3M Instrument Logger"
python server.py
# 브라우저에서 접속
http://localhost:8000/index.html

계측기 연결 방법

  1. USB↔RS-232C 변환 케이블로 계측기와 PC를 연결합니다.
  2. 상단 [연결 안됨] 버튼을 클릭합니다.
  3. 팝업에서 COM 포트를 선택하고 연결을 클릭합니다.
  4. 상단이 [연결됨](초록)으로 바뀌면 측정 시작 가능합니다.
⚠ 포트 선택 창에 장치가 없으면 드라이버 미설치 또는 케이블 미연결 상태입니다. CH340 / FTDI 등 USB-Serial 드라이버를 설치하세요.

  • HIOKI 3540 본체에서 RS-232C 인터페이스가 활성화되어 있는지 확인
  • 통신 속도를 9600 bps로 설정

앱 사용 방법

  1. Hioki 3540 카드를 클릭하여 진입합니다.

  3. 연결되면 400ms마다 자동으로 저항값이 갱신됩니다.
  4. 사이드바에서 테스트 방법(MSL-2 등)을 선택하면 그룹 크기와 컬럼이 자동 설정됩니다.
  5. 기록 시작 버튼을 누르면 측정값이 그리드에 자동 채워집니다.

계측기 측 설정

  • Keithley 2700 메뉴에서 RS-232 인터페이스 선택
  • 통신 속도 9600 bps, 8N1 설정
  • 연결 시 앱이 자동으로 *RST → SYST:REM → SENS:FUNC "FRES" 시퀀스를 전송합니다

앱 사용 방법

  1. Keithley 2700 카드를 클릭하여 진입합니다.
  2. 연결하면 약 3초 후 자동 초기화가 완료되고 측정이 시작됩니다.
  3. 측정값이 9.90E+37이면 "Over Flow"로 표시됩니다 — 프로브가 연결되지 않은 상태입니다.
  4. 테스트 방법, 측정 방식(2선/4선), NPLC를 사이드바에서 설정합니다.
  5. 기록 시작으로 그리드에 측정값을 기록합니다. 오버플로우 값은 자동으로 기록에서 제외됩니다.

🔴 중요 — Data Bits 7, Parity Even, Stop Bits 2입니다. 다른 계측기와 다르므로 반드시 확인하세요. 설정이 틀리면 응답 없음 현상이 발생합니다.

계측기 측 설정

  • Mitutoyo VL-50 후면 RS-232C 포트 사용
  • 본체 통신 설정: 9600 bps, 7 data bits, Even Parity, 2 Stop Bits
  • 연결 시 앱이 자동으로 CS\r\n (리셋) 명령을 전송합니다

앱 사용 방법

  1. Mitutoyo VL-50 카드를 클릭하여 진입합니다.
  2. 연결 후 300ms마다 두께값이 소수점 5자리로 자동 갱신됩니다.
  3. 사이드바에서 테스트 방법(MSL-2, ETM-7 등)을 선택하면 그룹 크기가 자동 설정됩니다.
  4. 기록 시작으로 그리드에 두께값을 기록합니다.
💡 측정값 단위는 mm, 소수점 5자리까지 표시됩니다. 기본 테스트 방법은 MSL-2, 그룹당 6개입니다.

데이터 전송 방법

⚠ LT-1000은 능동 측정이 아닌 수동 전송 방식입니다. 아래 절차를 따르세요.
  1. LT-1000에서 Select 버튼으로 데이터 메뉴로 이동합니다.
  2. 🔴 Run 상태(빨간 LED)에서 평가를 진행합니다.
  3. Print(🔴 빨간 LED) → Enter → Enter를 누릅니다.
  4. 약 3~5초 후 타이머가 종료되면 데이터가 앱에 자동으로 기록됩니다 (녹색 표시).

로드셀 캘리브레이션

  1. 로드셀을 최상단으로 이동 후 고정핀을 체결합니다.
  2. Select + Enter 3초 → Setup(🔴 빨간 LED) → Enter
  3. 디스플레이에 LC 0.000 확인 → Enter (무부하 0점 교정)
  4. 디스플레이에 HC 1000 표시 → 1 kg 분동을 올린 후 Enter
  5. 추를 제거하고 로드셀을 파지한 채 고정핀을 해제하고 조심히 내려놓습니다.

ST FULL 해결 방법

메모리(20개)가 가득 찬 경우 ST FULL 오류가 발생합니다.

  1. Select → Print(🔴) → ▲ × 2 → DL → Enter
  2. Select + Enter 3초 → 초기화 완료
  3. 이후 다시 평가를 시작합니다 (녹색 표시).

Photo Editor 비-시리얼 도구

RS-232C 불필요. 파일 업로드 또는 스마트폰 카메라 연동으로 사진을 수집하고 엑셀(.xlsx)로 내보냅니다.

기본 사용 흐름

  1. Photo Editor 카드를 클릭하여 진입합니다.
  2. 좌측 📁 파일 선택 / 드롭 버튼으로 사진을 업로드하거나, 스마트폰 카메라를 연동합니다.
  3. 사이드바 파일 목록에서 사진을 클릭하면 메인뷰에 크롭 영역이 표시됩니다.
  4. 크롭 영역을 드래그하여 원하는 범위를 설정합니다.
  5. 하단 다음 단계 ▶를 클릭하면 Step 2 그룹 미리보기로 이동합니다.
  6. 엑셀로 내보내기를 클릭하면 .xlsx 파일이 생성됩니다.

스마트폰 카메라 연동

  1. 시작.bat로 앱을 실행합니다 (python server.py 필수).
  2. 사이드바 ▶ 폰 연동 시작을 클릭합니다.
  3. USB 연결 시: ADB가 자동으로 포트를 연결합니다. 폰 브라우저에서 http://localhost:8000/phone.html을 엽니다.
  4. WiFi 연결 시: 폰과 PC를 같은 WiFi에 연결 후 폰 브라우저에서 http://[PC의 IP]:8000/phone.html을 엽니다.
  5. 폰 화면에서 ● 촬영 → 업로드를 누르면 사이드바에 사진이 자동으로 추가됩니다.
💡 PC에서 카메라 라이브뷰를 클릭하면 초점이 이동합니다. 길게 누르면 초점이 고정됩니다 (폰 카메라가 지원하는 경우).

덮어쓰기 촬영

사이드바 파일 목록에서 체크박스를 선택한 후 새로 촬영하면 해당 파일이 새 사진으로 교체됩니다. 잘못 찍힌 사진을 재촬영할 때 활용합니다.

연결 관련
